# Web 云端存储策略

更新日期：2026-09-15。适用于当前 Web 版本；后续桌面客户端的本地与云端共存方案尚未开发。

## 正式存储与登录

- Web 必须通过 Supabase Auth 验证当前用户后才能进入工作台。未配置、登录验证中或验证失败时显示入口状态，不创建匿名工作区。
- 工作区内容、资料、笔记、版本、对话及批注以 Supabase 数据库为唯一正式存储；文件原件使用私有 Supabase Storage，并受当前用户权限约束。
- 浏览器中的当前会话工作区、待上传文件与知识审核编辑仅在内存中暂存。认证 Cookie 用于登录；Web 不把业务数据写入 IndexedDB、localStorage 或 sessionStorage 作为日常存储。
- 刷新后的正式资料从云端读取。首次云端读取失败时停止进入工作台，不以空工作区覆盖已有账号，也不切换到本地工作区。
- 旧版 IndexedDB 实现保留用于读取既有资料及历史协议测试，不是当前 Web 的正式存储。后续桌面端才计划提供本地与云端共存、持久缓存及离线能力。

## 保存、断网与退出

“已保存到云端”必须有云端确认。提交响应不确定时核对当前云端版本；内容对象的键顺序不同不构成内容差异，数组顺序仍有意义。未经核对，不自动重复不确定的写入。

断网或云端拒绝保存时，未保存的修改只存在当前页面，页面提示等待确认或连接错误。刷新、关闭页面可能丢失这些修改；需要保留时先导出备份，再重新连接或处理差异。当前工作区仍受 3 MiB 云端快照容量保护，这不是承诺无限云容量。

Web 不提供“保留本机草稿后退出”。正常退出等待云端确认；冲突或无法确认时先处理差异。选择云端版本前，必须成功导出当前内容的完整保护备份；备份缺少原件时，不自动丢弃当前待保存内容。

切换账号、退出或卸载工作台会清除该页面的业务内存，旧会话的晚到读取、排队写入和保存回调不能回写新会话。注销账号仍以服务端确认和会话隔离为依据；当前 Web 不新增旧版 IndexedDB 的业务副本或删除标记。

知识审核中尚未应用的勾选、正文编辑属于当前页面的暂存内容，刷新后不恢复。应用建议或恢复备份的成功提示必须等待正式工作区的云端保存确认。

## 旧匿名资料迁移

原来的“资料副本存在差异”由旧版匿名资料和非空云端账号相遇时触发。当前 Web 不再日常发现或自动迁移匿名工作区，设置中的“导入旧版资料”提供显式恢复入口：

1. 只在主动打开入口后读取旧版匿名工作区，并生成 ZIP 与导入预览。
2. 作为新增副本加入当前已登录云端账号，保留账号已有内容，不覆盖它们。资料、资料库、笔记、历史和引用关系重新绑定身份；新增资料默认关闭 AI 使用。
3. 检查原件是否可读。缺少原件时必须明确同意只导入包中已有内容，不能把文字恢复称为原文件恢复。
4. 同一个已准备导入计划的失败重试保持稳定身份，并等待云端确认；并发提交同一计划也等待同一次确认。完成后再次打开入口并重新导入会创建新副本，当前没有跨计划自动去重。
5. 原来的浏览器副本不会自动删除。可在预览中下载旧版备份 ZIP；后续清理旧副本是独立动作。

## 验证与边界

当前自动回归覆盖登录门禁、无浏览器持久业务存储、首次云端失败零覆盖写入、刷新云端读取、账号切换、退出晚到任务、知识审核内存隔离、备份追加与同计划重试、云端保存确认、保存响应丢失后的版本核对，以及保护备份失败时禁止使用云端覆盖当前编辑。

真实浏览器已核对已登录工作台、云端确认状态及上述旧副本预览。模拟存储与网络测试不代替真实跨账号、双设备并发和断网验收；本次没有应用云端迁移、创建凭据、部署或启用持久后台任务。原有 19 份已应用迁移、5 份待迁移及 M0 待验收范围见[开发状态](IMPLEMENTATION_STATUS.md)。
