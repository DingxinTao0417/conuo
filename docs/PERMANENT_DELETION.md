# Conuo 资料彻底删除

更新日期：2026-09-14。本文对应 PRD **DAT-03**，记录 Web 中资料彻底删除及关联另存内容的选择合同。选择清理迁移 `20260915060323_source_purge_saved_content_selection.sql` 已通过本地 SQL 回归与统一检查，尚未应用到连接项目或 PRODUCTION。实际部署状态见[云端配置](CLOUD_SETUP.md)，最终验证记录见[开发状态](IMPLEMENTATION_STATUS.md)。

## 默认保留与选择粒度

资料必须先进入回收站。登录云端账号且工作区保存确认后，才能取得服务端预览并执行彻底删除；匿名本机模式不能替代云端清理事务。

| 对象                   | 默认行为                                                                             | 明确勾选后的行为                                                               |
| ---------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| 原资料                 | 删除当前原件、所有保留历史原件、网页快照、解析与检索派生记录                         | 不提供只删当前原件的降级操作；单个历史版本清理见[文件版本](FILE_VERSIONS.md)   |
| 独立笔记、知识页       | 保留用户当前正文和全部历史正文，移除该资料的普通引用及手工摘录身份                   | 逐篇删除当前正文及全部保留历史，不能只删其中一段或某个版本                     |
| 对话                   | 保留全部消息、历史回答和个人笔记证据快照；剥离该资料的原始引用，相关尝试禁止自动重试 | 逐个删除整段对话及全部消息，不能只删某条回答                                   |
| 人工批注、手工知识关系 | 有人工文字的批注和需要删除的手工关系阻止操作                                         | 先另存人工内容，或通过各自入口明确处理，再重新核对影响                         |
| 系统生成记录           | 清理直接关联的解析任务、整理记录及 AI 关系                                           | 选删笔记还会清理确切关联该页的整理任务和 AI 关系；额外关联的手工关系仍阻止操作 |

所有笔记和对话默认不勾选。选中的整篇内容可能同时包含其他资料和人工文字，界面明确说明这种影响。未选会话中的个人笔记历史摘录不会因为另存笔记被选删而被偷偷改写；引用失效与历史文字仍可阅读是两个不同状态。

候选只按已记录的结构化身份判定：笔记当前及历史的 `citations` / `manualExcerptRefs`；对话的直接资料、选定资料、对照版本对、消息引用和个人笔记依据，以及回答尝试中的冻结范围、版本与对照身份。正文中恰好出现某个 ID、相似文字或看起来像 JSON 的文本不会被当作关联依据。知识关系端点按既有知识页快照语义识别，不能把 ID 相同的其他实体当作该页。

## 权威预览与确认

预览返回 `contentSelection`：候选笔记的身份、标题、类型和正文版本总数，候选对话的身份、标题和消息数，以及当前选择。正文版本数**包含当前正文**。影响中的 `removedNotes`、`removedNoteVersions`、`removedConversations` 和 `removedMessages` 显示将删数量；保留对象与引用数只计未选对象。

每次改变勾选都重新核对云端范围，并清空资料名称确认输入；读取中、读取失败、返回选择不一致、有手工内容阻止，或上下文已经变化时，不能提交。重新核对会清空勾选，回到默认全部保留。旧环境若尚未返回选择合同，界面只提供默认保留另存内容的资料删除，不替用户推断或提交选择。

客户端与服务端均校验选择结构、唯一 ID 和候选归属。ID 沿用工作区规则 `^[a-zA-Z0-9_-]{1,100}$`；笔记最多 10,000 个、对话最多 5,000 个，不缩小已有工作区合法容量。HTTP 选择正文设 2 MiB 上限。失效或不属于当前账号候选的 ID 会被拒绝，不静默过滤。

服务端从已认证账号的工作区建立预览。指纹绑定资料、关联对象的完整正文与历史、对话消息、生成依赖和选择，不能只比较数量或更新时间。后台任务的已暂存结果及状态也参与复核。提交时在账号锁和工作区行锁内重新计算预览，检查指纹及预期 revision；工作区 CAS 冲突或内容变化会拒绝旧确认。需要先保存本机修改，不能用删除操作覆盖尚未同步的正文。

## 删除事务与防复活

资料元数据、选中笔记和对话、生成依赖及读投影在同一数据库事务中更新。资料删除记录和账号隔离的另存内容墓碑绑定确切 `sourceId`、`noteId` 或 `conversationId`；墓碑不存用户正文。工作区写入触发器覆盖普通保存、快速保存、后台任务写入和特权快照更新，拒绝把已删的同一记录身份重新保存回来。删除关联后台整理任务包括已暂存结果，避免迟到工作重新发布旧内容。

客户端提交期间暂停普通写入，复核当前账号及会话，确认服务端返回的资料和选中对象已经不存在、revision 已推进。先耐久保存服务端返回的确切快照，再考虑释放本机原件。若云端已提交但 IndexedDB 保存失败，会保留新状态并提示“云端已完成、本机尚未保存”，暂停同步并提供重试，不能显示全部清理成功。

本机保存或原件清理期间切换账号，旧操作会拒绝成功返回，不向新账号发布状态。页面也会在显示成功和关闭弹层前复核原账号、工作区 token、缓存模式、确切操作及弹层目标；账号／上下文变化、打开其他弹层或组件卸载会使旧操作的界面发布失效。已提交的原账号结果仍按准确快照保留，不能通过迟到提示误关新账号的弹层。

墓碑禁止恢复同一记录身份，不阻止用户主动重新创作内容或按[备份恢复](BACKUP_RESTORE.md)的新增副本合同建立新身份。服务器无法查找用户外部复制、改写或主动导出的所有相似文字。

## 模型结果缓存与额度账本

模型结果缓存与工作区分表存储；浏览器没有 `ai_requests` 表的读取和写入权限，ZIP 不导出这张账表，用量接口只读取数量。

本地迁移已将已完成结果的清理收窄到当前账号的相关结果：删除前收集所选会话中 `messages[].attempt.id`、删除的工作区整理记录 `request.requestId` 和关联后台任务 `model_request_id`；结果中的结构化资料／所选笔记引用也会明确参与匹配。无关已完成结果和其他账号结果保留。这里的 `attempt.id` 就是请求 ID，不能用消息 ID、问题正文或相似答案猜关联。这项 SQL 修订仍未应用到云端。

清理结果时保留请求账行、指纹和 `created_at`，仅清空结果、设置不可重放的失败状态及受控错误码。失败和已取消请求仍计入当日预占次数，不能通过删除记录获得额外额度。账表不保存任意用户错误正文。一般保留期仍采用账号下次预占请求触发的惰性清理，不保证到期立即物理清除，详见[模型配置](MODEL_SETUP.md)。

既有资料删除会将当前账号全部运行中的模型请求置为失败，阻止迟到结果写回；这项兜底仍保留。账本只记录请求指纹，没有完整会话／资料范围绑定，Reader 的尝试身份在终态才进入保存消息，当前不能精确证明所有在途请求的关联。完成 RPC 只能更新仍处于运行状态的同账号请求，不能重建已终止结果。

已经在删除前进入服务器响应或网络传输的结果，以及已发送到用户设备、主动下载或导出的内容，无法由删除事务收回。未联网设备也可能暂存旧副本。不能宣称已撤回所有网络字节或所有相似表述；真实跨端删除同步和在途响应边界仍需完整验收。

## 原件清理与验收边界

提交成功先表示逻辑删除和元数据提交，**不表示云端原件已经全部物理删除**。事务枚举确切保留版本的 canonical Storage 路径，交给既有 cleanup outbox；服务端受保护执行器通过租约、心跳、有限重试与退避清理原件。`404` 是幂等成功，其他错误保留受控失败状态；所有对象确认完成后，父级 purge 才标为 `completed`。本机字节也只在确认没有任何保留工作区仍引用且可信账号归属一致时删除。

本地回归覆盖默认保留、选择整篇正文及历史、整对话删除、手工内容阻止、严格候选与容量校验、完整内容指纹、同账号保护和失败状态。SQL、API、协调器与浏览器最终结果以本轮统一记录为准，不把单连接 PGlite、受控 IO 或本机页面观察当作真实 Supabase 验收。

上线前还需在目标环境核对五份待迁移的执行顺序和权限，验证真实双账号拒绝、双设备 CAS、陈旧标签页／后台结果防复活、网络中断后的状态复核、原件清理失败重试及最终 Storage 删除。资料物理清理时限与服务端备份删除重放仍须按 PRD 独立验收，不能由本机测试推定已满足。
