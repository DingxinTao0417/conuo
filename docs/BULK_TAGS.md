# 批量添加资料标签

Conuo Web 的资料列表支持选择多份资料，保留每份已有标签并追加人工输入的标签。确认前显示实际去重后的选中数量；执行后逐份显示“已修改”“无需修改”或“失败”及原因。该操作不调用 AI，固定标签和关闭 AI 的资料也允许人工修改。

## 处理与重试

输入用英文或中文逗号分隔，沿用单份人工标签的 trim 与精确去重规则，不自动改名或合并不同大小写的标签。每份资料最多 100 个标签，每个标签最多 100 个 UTF-16 单元。空输入、非法选择和输入整体超额拒绝执行；单份资料缺失、处于回收站或追加后超过标签上限时，该项失败，其他有效项继续。

一批修改形成一个工作区写入。完整 UTF-8 工作区超过 3 MiB 时整批拒绝，不发布部分成功。领域选集上限沿用工作区的 5,000 份资料，结果数量不会静默截断。临时结果仅用于当前弹窗，不新增业务历史或云端表。

点击“仅重试失败”只处理上次失败的 ID，使用最新工作区资料、标签和删除状态；成功项与无需修改项保留原结果。恢复回收站资料或清理满额标签后可重试。资料换版、选择或上下文改变会作废旧操作，需重新打开弹窗核对。

## 保存确认

逐项结果在 `updateDurably` 确认当前浏览器持久写入后显示，不把内存修改或云端排队视为本机已保存。全批无需修改或失败、以及本机写入失败后的重试，仍等待实际快照写入确认。

写入失败时保持输入，提示当前内存可能已有标签修改，并提供本机保存重试；重试可能显示“无需修改”，但仍保存该快照。云端是否同步以工作区状态为准。本机确认不能替代云端确认。

账号、会话 token、缓存模式、选择与弹窗身份在同步 reducer 和保存完成后核对。用户主动关闭弹窗不会回滚已经执行的写入；旧 reducer 不能进入重开的弹窗或新工作区，迟到结果与错误也不能发布给新上下文。

## 验证边界

本地回归覆盖真实人工标签领域函数、生产面板与 Workspace 集成，包括部分失败、只重试失败、容量拒绝、无需修改保存、本机写入失败及上下文变化。桌面、iPad 和手机核对使用隔离合成样例及模拟保存，不代表真实云端并发已验收。本说明仅覆盖 SPC-03 的批量标签；批量空间关联与移入回收站已独立补齐本机确认及失败重试，见[批量资料操作](BULK_SOURCE_ACTIONS.md)。统一结果见[开发状态](IMPLEMENTATION_STATUS.md)。
