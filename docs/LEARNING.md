# 学习与复习

学习题目保存在独立的云端学习表中，不写入工作区快照。题目可以来自用户创建、AI 出题或区域学习；AI 生成的题目只在用户编辑并点击“加入复习”后保存。题目会保留创建时的原文引用快照，复习时引用仍按资料和版本核对。

## 复习队列

复习空间会显示当前可复习的到期题目和新题。暂停复习后，服务端队列为空，侧栏不显示到期角标。题目状态可以暂停、恢复或归档；删除题目是软删除，账号删除时由外键级联清理。

复习卡片支持选择题、填空、简答、推导和回忆题。查看答案后，学习者选择“忘了”“困难”“记得”或“轻松”。服务端使用 FSRS 根据当前卡片、目标记忆保持率和评分计算下次时间；浏览器显示的间隔只是预览，最终以服务端结果为准。并发版本变化时不会重复记录，页面会刷新队列并提示题目已在其他设备复习过。

## 设置

设置页的“学习”分组提供每日新题上限、目标记忆保持率和暂停复习。目标记忆保持率的界面范围为 0.80–0.95，默认值为 0.90；设置保存到 `learning_settings`，跨设备同步。

## 数据与删除

题目、复习状态和复习日志通过学习表保存，题目引用只指向资料版本的可核对切块。资料或历史版本彻底清理后，题目保留，但相关引用会被移除并标记来源已清理；复习页面不把新的版本当成旧引用。账号注销由数据库外键级联删除学习数据。

## 学习反馈边界

AI 批改只提供反馈和建议评分，学习者可以自行改选评分。阅读完成、一次答对或 AI 判断都不会自动标记“已掌握”；产品只展示复习记录和反馈。
