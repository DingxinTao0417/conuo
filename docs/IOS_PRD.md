## 1. 范围决定与产品原则

用户已要求在现有 Web 基础上开始其他端设计开发。iPhone 不照搬桌面的多栏布局，以较短操作链完成收集、阅读和理解；账号、资料身份、笔记格式、引用和云端结果仍与 Web 共用。

移动首版正式资料全部保存云端；本地正式资料库、持久离线编辑和离线下载包未纳入此次范围。安全保存登录凭据、前台内存草稿和操作系统临时文件具有不同用途，不能把它们称为本地资料库。

- 已完成 Web 业务优先复用服务合同；React DOM、PDF.js 组件和 Tiptap 不能直接视为原生组件。
- 先交付可靠的云端核心流程，再扩展系统分享、拍照、多任务和学习增强。
- 不以缩小 Web 页面或可运行 Expo 工程宣称已完成 iOS App。
- 对尚不可用的能力显示真实原因；正式界面不展示可点击但无行为的“演示功能”。
- 云端 AI 仅发送用户授权范围；区域截图采用多模态输入，不要求先执行 OCR。
- 本文不授权购买 Apple 开发者资格、启用付费云构建或提交应用商店。

## 2. 核心任务与衡量方式

| 任务           | 触发情境                     | 成功结果                                   |
| -------------- | ---------------------------- | ------------------------------------------ |
| 快速保存       | 手机上看到公开文章或收到文件 | 选定知识库，明确保存结果，稍后能在电脑打开 |
| 接续阅读       | 通勤或课间继续一份已有资料   | 找到上次云端确认位置和关联问题             |
| 理解难点       | 阅读时遇到术语、段落或图表   | 选中范围发问，读到结构化回答并回查出处     |
| 留下自己的理解 | 想记录短笔记或修改知识页     | 输入不被键盘遮挡，云端确认后跨端可见       |
| 管理待办       | 看见导入失败或整理建议       | 了解原因，能重试、取消或接受建议           |

首轮评估记录任务是否完成、返回次数、丢失输入、错误恢复和引用定位结果。启动速度、内存和文件大小上限以实际设备测试决定，不把设计目标写成已经兑现的指标。

## 3. 分期与完成定义

| 阶段              | 交付内容                                                           | 进入下一阶段的证据                         |
| ----------------- | ------------------------------------------------------------------ | ------------------------------------------ |
| I0 工程与交互起步 | Expo 工程、原生导航、设计变量、能力状态、环境配置、基础适配        | 开发预览可运行；静态检查；iPhone 布局截图  |
| I1 云端学习核心   | 登录、资料列表、阅读、基本笔记、搜索、问答引用、云端保存、任务状态 | 真实 iPhone 与 staging API 完整任务验收    |
| I2 收集与阅读增强 | 系统文件、URL 导入、可靠分享扩展、区域学习、知识审核、完整导出入口 | 每种系统入口的冷启动、登录、失败与取消验收 |
| I3 学习和发布增强 | 后续练习、通知、无障碍完善、正式分发准备                           | 每个增量独立验收；获得发布与费用授权       |

I1 的主要资料来自现有云端库，也应有明确可工作的导入路径；原生文件选择未完成时可先提供 URL 导入，但不能宣称支持系统分享或任意本机文件解析。I2 完成后才满足完整的移动收集目标。

技术验证与功能交付分开记录。Expo Go 或模拟器只用于验证其支持的部分，分享扩展、认证回跳、阅读器原生模块和安装行为需要实际开发构建及设备证据。

## 4. 信息架构

底部使用“学习、资料库、问答、我的”四个一级入口。顶部搜索与添加按钮按页面上下文出现；笔记、知识页和任务中心由学习页及资料库进入，避免把所有 Web 栏目挤进底栏。

| 页面 / 逻辑路由     | 内容                           | 关键动作                           |
| ------------------- | ------------------------------ | ---------------------------------- |
| `auth/sign-in`      | 登录、注册、找回密码           | 登录成功恢复经过校验的目标         |
| `learn`             | 继续学习、最近知识库、待处理项 | 打开资料、进入笔记 / 知识页 / 任务 |
| `library`           | 全局资料、搜索、筛选           | 添加、选中、批量标签与移动         |
| `spaces/:id`        | 知识库概览及资料 / 知识 / 问答 | 切换知识库，明确当前范围           |
| `sources/:id`       | 原文、阅读工具、问 AI          | 引用定位、批注、查看版本           |
| `notes/:id`         | 笔记正文、依据、保存状态       | 编辑、历史、导出                   |
| `knowledge/:id`     | 已保存知识页或待审建议         | 查看来源、编辑、接受或弃用         |
| `questions`         | 全局或指定知识库的对话         | 继续、搜索、查看失败尝试           |
| `conversations/:id` | 问题、回答、范围与引用         | 停止、重试、另存笔记、回原文       |
| `collect`           | 文件 / 链接收集确认            | 选目标、检查重复、提交             |
| `tasks`             | 全局上传、解析与整理           | 查看结果、取消或重试               |
| `account`           | 账号、AI、存储、阅读与支持     | 设置、导出、退出、注销             |
| `trash`             | 已删除资料和影响说明           | 恢复、确认彻底删除                 |

以上为原生导航合同，不宣称已有对应后端 URL。对象参数使用稳定 ID；深链接解析和 Web 跳转适配在实现时集中处理。

### 4.1 导航规则

- **I-NAV-01 / I1：** 底栏入口始终指向全局页面；从知识库返回不得把全局学习页变为库内概览。
- **I-NAV-02 / I1：** 阅读器进入全屏内容栈，返回恢复列表筛选与位置；引用打开原文后可返回原回答段落。
- **I-NAV-03 / I1：** 切换知识库时取消旧范围的加载结果，当前标题、列表和 AI 范围同时更新。
- **I-NAV-04 / I1：** 缺失、删除、越权或旧版本到期显示对应状态，不显示上一个对象作为占位。
- **I-NAV-05 / I2：** 系统深链接、文件分享和恢复账号的目的不同，分开解析，不将外部参数直接当作已授权操作。
- **I-NAV-06 / I1：** 有未保存输入时返回、退出与关闭编辑均检查状态；手势返回遵守相同规则。

## 5. 页面设计与触摸要求

### 5.1 共用视觉语言

延用 Conuo 的品牌、色彩语义、圆角和信息层级。iOS 使用适合原生的列表、顶栏、底部面板和系统选择器；不复制桌面侧栏、悬浮鼠标提示或三栏布局。

单屏突出一个主要任务。正文、摘要和状态说明层级清晰；标签不压缩成不可辨认的彩色点。严重错误与破坏性操作同时有文字，不只用红色。

触摸目标按至少 44pt 的设计目标验证；正文支持系统文字大小，辅助信息可以换行。窄屏上横向滚动只用于确实需要的代码或表格，不让整页横向溢出。

### 5.2 阅读页

顶栏显示返回、资料名和更多；页码与阅读模式可以快速找到。“问 AI”打开底部面板或全屏对话，正文位置保留。关闭 AI 或点击引用回原文时，不把文档跳到第一页。

PDF 单页与连续阅读均保留。目录、批注列表、版本选择和显示设置按需打开；选段工具只在选区形成后出现。缩放时不将普通拖动误认成区域截图。

### 5.3 问答页

问题输入上方持续显示当前资料 / 知识库范围；键盘弹出后输入、发送和停止按钮仍可见。回答以标题、段落、列表、表格及可点引用结构化显示，宽表格局部横向滚动。

流式响应不强迫滚动已上滑阅读的用户；出现新内容时提供回到底部入口。停止、超时、额度不足与无资料依据使用不同终态。

## 6. 账号与生命周期

- **I-ACC-01 / I1：** Supabase 账号与 Web 一致；原生会话持久化使用经验证的系统安全存储，不把 token 放入普通键值存储或日志。
- **I-ACC-02 / I1：** 登录、刷新、退出和撤销会话可恢复；认证失败不能回退到本机空库。
- **I-ACC-03 / I2：** 确认邮件和找回密码回跳绑定发起事务；验证同设备、跨浏览器、冷启动、过期和重复消费。
- **I-ACC-04 / I1：** 账号切换释放前一账号内存和在途结果；前一账号的迟到响应不能进入新账号。
- **I-ACC-05 / I1：** 系统切入后台时尝试提交已允许的保存，但不宣称系统保证后台完成；恢复前台重新读取权威状态。
- **I-ACC-06 / I1：** 未获云端确认的编辑持续标识；退出前等待保存、导出当前内容或取消退出。

首个云端版本没有持久本地草稿保证。系统终止进程可能使尚未云端确认的内存输入丢失，因此编辑需及时保存，保存失败时明确风险与导出入口；不能显示“已安全保存在本机”。

认证安全存储保存的是登录材料，不含资料正文。正常退出清理会话材料；操作系统备份、应用重装与凭据残留行为必须单独验证后再写进帮助文案。

## 7. 数据、网络与同步边界

| 数据类型                     | 允许位置                   | 退出 / 重启行为                          |
| ---------------------------- | -------------------------- | ---------------------------------------- |
| 资料、笔记、对话、版本、位置 | Supabase 正式云端数据      | 重启重新授权读取                         |
| 当前阅读、选区、未确认输入   | 前台会话内存               | 不承诺跨进程保留                         |
| 登录凭据                     | 经验证的系统安全存储       | 按会话与退出规则管理                     |
| 文件选择 / 系统分享临时副本  | 有限生命周期的系统临时文件 | 完成、取消或过期后释放，不是可浏览资料库 |
| 用户主动导出的文件           | 用户选择的系统目标         | 归用户管理，不被应用云端删除承诺覆盖     |

- **I-SYN-01 / I1：** 拉取失败显示错误页，不以空列表初始化或覆盖云端数据。
- **I-SYN-02 / I1：** 保存区分“正在保存、云端已确认、保存失败”；只有服务器确认后才标为已同步。
- **I-SYN-03 / I1：** 写入绑定基础版本；并发冲突呈现本次输入与云端内容，保留用户选择机会。
- **I-SYN-04 / I1：** 请求提交但响应丢失时先查询权威结果；不能自动重复创建笔记或重发收费 AI。
- **I-SYN-05 / I1：** 网络恢复后重新验证账号、资料和版本；阅读缓存不能绕过删除与访问状态。
- **I-SYN-06 / I2：** 上传临时文件只用于用户已发起的任务，有容量、保留时限和清理策略；不保存成未授权离线库。

飞行模式下可继续查看当前仍在内存的内容，切换未加载资料明确要求联网；不显示“已下载”或“离线可用”。首次启动离线时提供重试入口。

## 8. 收集资料

### 8.1 文件与链接

- **I-IMP-01 / I2：** 使用系统文件选择器读取明确选择项，提交前显示名称、类型、大小、目标库和重复提示。
- **I-IMP-02 / I1：** 粘贴公开 URL 后预览可提取内容；失败可仅保存链接，不声称已建立正文索引。
- **I-IMP-03 / I2：** 文件类型支持范围遵循服务端与实际解析器；PDF、TXT、Markdown、DOCX 分别验证，扩展名不等于可解析。
- **I-IMP-04 / I2：** 超额、权限拒绝、云盘占位文件未下载、文件取消选择和破损分别提示；不删除原文件。
- **I-IMP-05 / I2：** 上传、原件保存、解析、索引、整理分别显示；成功上传不表示 AI 已能阅读全部内容。
- **I-IMP-06 / I2：** 失败保留已创建任务身份；重试遵循幂等合同，取消准确说明保留了哪些云端内容。

当前 Web 有浏览器解析路径，不能直接假定原生上传后服务端会自动解析全部格式。I2 必须落实原生解析适配或受控云端解析链路，再逐格式放开入口。

### 8.2 系统分享扩展

- **I-SHR-01 / I2：** 从 Safari 或文件应用选择分享至 Conuo，展示目标知识库、内容摘要与保存按钮。
- **I-SHR-02 / I2：** 未登录时引导打开主应用登录；待传内容仅在有期限的分享传输区保存，不能混入其他账号。
- **I-SHR-03 / I2：** 分享扩展被系统中止时不得显示成功；重新进入主应用检查已存在任务并展示真实结果。
- **I-SHR-04 / I2：** 账号在扩展打开期间变化时停止旧提交，重新要求选择范围；不静默使用最后登录账号。
- **I-SHR-05 / I2：** 原站需要登录或无法提取时仅保存授权的链接 / 用户分享文本，不能宣称读取受限正文。

分享扩展是单独的原生目标和验收项，不由普通 Expo 预览自动具备。设计完成、编译成功、真机从 Safari 分享成功要分别记录。

### 8.3 相机与图片

拍照收集属于 I3 可选增强，首次使用再请求权限；未授权时保留系统文件入口。导入照片、图像多模态解释和全文 OCR 是三个独立能力，不互相冒充。

## 9. 阅读与引用

- **I-RDR-01 / I1：** PDF 和结构化文本使用经验证的原生或受控阅读适配，保留资料 ID、版本 ID、物理页及文字锚点。
- **I-RDR-02 / I1：** 单页 / 连续阅读、目录、页码和缩放可触摸操作；旋转与键盘变化不丢位置。
- **I-RDR-03 / I1：** 云端阅读位置恢复前验证版本；版本改变时说明原因，不把旧页码硬套到新文件。
- **I-RDR-04 / I1：** 点引用打开确切来源版本；删除、历史到期和无法定位分别提示，可选择当前版但不可冒充旧依据。
- **I-RDR-05 / I2：** 选段保存批注使用共用锚点语义；中文、emoji、跨段落及长选区单独测试。
- **I-RDR-06 / I2：** 导出或在其他应用打开原件由明确按钮触发，使用当前授权下载，不长期缓存带权限的临时地址。

扫描 PDF 可阅读不等于可全文搜索。无文本时解释限制，允许单页局部视觉提问；解析部分失败必须展示覆盖缺口。

## 10. AI、笔记和知识整理

- **I-AI-01 / I1：** 当前文档、知识库和受限“资料 + 我的笔记”范围继承主 PRD；发送前展示实际范围。
- **I-AI-02 / I1：** 结构化回答、来源、推断、失败和停止状态均能在窄屏阅读；历史助手内容不作为隐藏新依据。
- **I-AI-03 / I1：** API 验证身份、额度、资料版本与 AI 权限；客户端只有公开配置和用户会话，不含服务端密钥。
- **I-AI-04 / I2：** 框选区域后预览、选择解读 / 提问 / 出题并确认发送；图片仅覆盖选区，结果绑定原文版本。
- **I-AI-05 / I1：** App 后台后流式连接可能中断；前台恢复查询终态，不重发原问题或伪造完整回答。
- **I-NTE-01 / I1：** 支持基本段落、标题、列表、引用的编辑与保存；格式子集与 Web 互通，未知块可读且不被静默删掉。
- **I-NTE-02 / I2：** 编辑完整知识页或复杂表格时提供合适布局；暂不支持修改的块显示原因，可保留原块。
- **I-KNO-01 / I2：** 查看摘要、标签及知识页建议；按项接受、编辑或弃用，明确依据和生成状态。
- **I-KNO-02 / I2：** 审核期间基础版本发生变化时要求刷新或合并，不接受过时建议覆盖用户正文。
- **I-KNO-03 / I1：** 任务由云端调度继续执行；手机离开页面不表示任务取消，后台成功返回主应用可查看。

一次区域练习不代表完整复习系统已交付。主动练习、作答记录和掌握状态按主 PRD 的后续学习阶段实施。

## 11. 端到端任务

### 11.1 从电脑接续

1. Web 将资料与阅读位置保存到云端。
2. iPhone 登录，学习页展示最近资料；点击后复核版本并定位。
3. 发问并点击引用核对，再保存自己的短笔记。
4. 云端确认后回到 Web，确认正文、引用和版本一致。

### 11.2 Safari 收集后继续学习（I2）

1. 用户在 Safari 主动分享一个公开文章链接。
2. 选择 Conuo 与目标知识库，查看预览并保存。
3. 展示保存或待处理状态，打开主应用定位对应任务。
4. 解析成功则阅读正文；仅保存链接则明确提示提取限制。
5. Web 可见同一资料身份，重复分享有复用 / 副本选择。

### 11.3 手机阅读到短笔记

1. 选取原文段落并提问，确认范围后发送。
2. 在键盘、流式输出与滚动间切换，输入和原文位置不丢失。
3. 将回答另存笔记，区分 AI 内容和本人后续编辑。
4. 保存失败时保留当前输入并提供重试 / 导出，成功后再离开。

### 11.4 断网、后台与冲突

1. 编辑期间断网，展示未保存状态；当前内容保留在会话内存。
2. 同时在 Web 修改同一笔记，再恢复手机网络。
3. 展示版本冲突，选择复制本次输入或合并后保存。
4. 切入后台再返回时重新校验；进程已被系统结束则从云端恢复，不能显示不存在的草稿。

## 12. 异常与恢复

| 场景               | 用户应看到                   | 恢复方式                     |
| ------------------ | ---------------------------- | ---------------------------- |
| 首次拉取失败       | 页面加载失败，不是空账号     | 重试、检查登录               |
| 无网络             | 当前已加载内容可看，提交受限 | 恢复网络后重新确认           |
| 上传被系统中止     | 原任务待确认或失败，不假成功 | 查询云端，显式重试           |
| 当前资料已删除     | 来源失效与返回入口           | 回资料库，保留独立历史文字   |
| 额度耗尽           | AI 未执行或明确终态          | 查看用量，编辑问题稍后提交   |
| 图片过大或裁剪无效 | 区域未发送                   | 重新框选，不自动压成不可读图 |
| 会话过期           | 暂停写入、登录入口           | 恢复原账号再校验基础版本     |
| 键盘遮挡或大字体   | 可滚动输入区域、可见操作     | 收起键盘、移动焦点           |
| 找回链接失效       | 链接已失效或已使用           | 返回找回入口，重新发起       |

## 13. 无障碍、隐私和权限

- VoiceOver 可读出按钮名称、当前页、选中状态、保存状态和错误；图标不只报文件名。
- 阅读顺序随页面层级而非视觉绝对位置，弹窗关闭后焦点回到原触发项。
- 动态字体和减弱动态效果设置应用于主要页面；状态更新不持续打断读屏。
- 文件访问仅针对用户选择的项目；通知、相机等权限按实际操作时请求。
- 日志不包含账号凭据、私有原文、完整 Storage 地址和截图字节；诊断由用户明确导出。
- 推送通知内容默认不展示私有正文；通知未实现时不显示无效开关。
