# 批量关联学习空间与移入回收站

Conuo Web 的资料列表支持选择多份资料，批量新增学习空间关联或移入可恢复的回收站。弹窗显示去重后的实际选中数量，并在本机保存确认后逐份展示处理结果与原因。这两项人工管理操作不调用模型；关闭 AI、资料未授权 AI 或固定标签，不会单独阻止人工操作。人工追加标签另见[批量标签](BULK_TAGS.md)。

## 逐份处理

| 结果                 | 新增空间关联                                                       | 移入回收站                               |
| -------------------- | ------------------------------------------------------------------ | ---------------------------------------- |
| 已处理（`accepted`） | 至少新增一个所选空间的关联；保留原有关联，不复制文件               | 新增回收时间，保留原文件、正文和历史版本 |
| 无需修改（`noop`）   | 已关联全部所选空间                                                 | 已在回收站                               |
| 失败（`failed`）     | 资料缺失、已在回收站、当前版本等待或正在解析，或新增后超过关联上限 | 资料缺失，或当前版本等待或正在解析       |

一份资料失败不会阻止其他有效资料。请求身份不合规、没有选择资料、关联操作未选择空间，或任一所选空间已缺失／归档时，整次操作拒绝执行，不悄悄缩小目标空间范围。

移入回收站后，资料退出新的搜索与问答范围；关联关系和已保存的历史内容保留。相关导入任务沿用现有回收逻辑取消，不把软删除当作彻底删除，也不清除另存笔记或对话。当前版本存在以下任一状态时，该项先失败，需明确取消解析或等待完成后重试：

- 资料自身为 `parsing`。
- 同一资料、同一当前版本的导入任务为 `queued` 或 `running`，已保存原件且处于 `parsing` 阶段。

仅保存原件、索引阶段、已失败／取消／完成的任务，以及保留旧版本的解析任务，不单独构成当前版本的解析保护。

## 本机保存确认

一批操作形成一个工作区写入。内存可先显示资料的关联或回收变化，但弹窗只有在 `updateDurably` 确认实际 IndexedDB 写入后，才展示“本机保存已确认”和逐项结果。全批无需修改或失败也等待真实快照写入；内存更新、云端排队或请求发出均不代表本机保存成功。

保存完成后还读取协调器当前账号的最新工作区，复核已处理项及无需修改项的资料版本、回收时间和所选空间关联，关联操作同时复核目标空间仍可用。若等待期间发生换版、恢复、解除所需关联或空间归档，旧确认被拒绝，不能按旧写入快照冒充当前成功。

账号、会话 token、缓存模式、选集和弹窗身份在 reducer 与保存完成后复核。用户可主动关闭弹窗；已经执行的写入不会回滚，迟到 reducer、结果或错误不能进入重开的弹窗或新工作区。

本机确认只说明该次浏览器持久写入已获确认，并且结果在复核时仍符合当前状态。云端是否完成同步，以工作区保存提示为准；本说明不承诺已云端同步。

## 两种重试

**尚未确认保存：重试本机保存。** 写入失败时，修改可能已留在内存，弹窗保留首次实际处理结果作为临时记录。重试验证当前后置条件，保存包含最新独立编辑的当前工作区快照，不再执行关联或回收，也不把首次已处理项重新算成“无需修改”。首次成功 ID、每项时间、累计新增关联数与后续交接范围因此保留。若目标状态已变化，拒绝重存，需重新核对资料；不会用旧数据覆盖新编辑。

**已经确认保存：仅重试失败。** 用户明确点击后，仅用上次失败的 ID 在最新工作区重新处理。已处理项与无需修改项保留原结果，新成功项追加到累计结果；恢复资料、等待解析完成或修复缺失资料后可重试。重试本身也等待本机确认；若再次写入失败，继续使用快照重存，不重复业务操作。

这些结果只驻留当前弹窗内存，不新增业务历史、云端表或 ZIP 内容。关闭或刷新后不会恢复临时结果；实际关联和回收状态仍按普通工作区保存规则保留。

## 成功资料的整理交接

关联确认后，“审核标签建议”仅交接本批实际新增过至少一个关联的资料 ID，以及用户选择的本批目标空间。已经完全关联、失败或未选的资料不加入范围；失败项后来成功时，累计交接范围包含这些新成功项。进入整理前仍复核资料版本、回收状态、目标关联和空间可用性，失效范围不能继续。

交接只打开整理页面并保留固定选集，不自动发起分析或应用标签。AI 授权、正文、模型配置、同步与请求数量等条件由整理流程独立核验；超过其单次范围需用户明确调整，不能默默选择前几份。详见[资料整理与审核](ORGANIZATION.md)。

## 容量与验收边界

领域上限沿用当前工作区模型：每次最多选择 5,000 份资料和 500 个学习空间，每份资料最多关联 500 个空间。结果逐份保留，不静默截断。修改后的完整 UTF-8 工作区超过 3 MiB 时整批原子拒绝，不发布假的部分成功；失败项重试和未确认快照重存同样检查该上限。

当前实现仅覆盖 Web；手机与 iPad 使用响应式网页，不代表原生端已经实现。本地回归核对逐项结果、真实历史版本、解析保护、容量拒绝、协调器持久确认与失败重存；真实 Supabase 并发、跨设备传播和模型质量不由这些本地检查证明。统一验证与发布状态见[开发状态](IMPLEMENTATION_STATUS.md)。
