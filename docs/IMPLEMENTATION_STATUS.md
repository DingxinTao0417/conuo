## iPadOS 原生 PDF 文件导入（2026-09-23，本地实现）

资料库与学习首页新增系统“文件”PDF 选择入口（单份 ≤30 MiB），PDFKit 提取按页文字；SHA-256 去重与 workspace 3 MiB 容量预检后调用现有原件预留与完成 RPC，向私有 `originals` Storage 上传原始字节，再以 workspace revision CAS 写入资料。云端原件和资料记录都确认后才显示成功；AI 授权默认关闭。PDF 资料页现已接入私有原件下载、PDFKit 原始页面和 PencilKit overlay；提取文本只用于检索/引用。`PKDrawing` 现在会按账号、资料版本和页码自动保存到本机 Application Support，并在重新打开 reader 时恢复；独立 ink migration、intent/commit API、私有 Storage 和 Web PNG 预览已部署到 staging。没有修改生产资源。DOCX / Markdown / TXT 原生导入、Pencil 云端真实验收、P1 其余真机闭环仍待验收。

本地验证：移动端 108/108 测试通过，类型检查通过；Xcode 27.0 / Expo SDK 57 在已连接 iPad `dapi` 真机构建通过（0 errors / 0 warnings）。真机截图[显示已导入的 PDF 资料](evidence/ipados-pdf-import/2026-09-23-imported-pdf-in-library.png)，资料库已读回一份 PDF；本机恢复仍需要在同一份 PDF 上完成退出/重进实机复测。

真机错误记录：首次选择 PDF 时 `expo-crypto` 原生桥因收到 `ArrayBuffer` 而报 `NotTypedArrayException`，错误发生在 SHA-256 计算阶段，未上传原件。已改为传入复制后的 `Uint8Array`，修复后重新启动 iPad 应用并由 Metro 成功打包；需用户再次选择 PDF 才能验证后续 PDFKit 提取、Storage 上传和 workspace CAS。

第二次真机错误为 `Cannot read property 'rest' of undefined`，实际发生在原件上传的 Supabase RPC 预留调用：抽取 `client.rpc` 丢失 receiver。已绑定 `client.rpc`；同时保留 PDFKit Promise 注册修复。Xcode 真机构建通过，移动端 108/108 测试与类型检查通过，尚未确认修复包实际选 PDF 后的后续阶段。

原始 PDF 页面首次打开又复现 `undefined is not a function`；已将原件缓存从 `Directory.create` 改为直接写入 `Paths.cache`，并让错误显示缓存阶段。修复包已由 Metro 重新加载，原始 PDF 和 Pencil overlay 的真机复测待用户再次点入资料。

随后真机显示“读取原件字节失败”：React Native Blob 在当前运行时没有可用的 `arrayBuffer()`。已增加 `FileReader.readAsArrayBuffer` 回退；移动端 108/108 测试和类型检查通过，修复包已重新加载，原始 PDF 打开和 Pencil overlay 仍待真机复测。

## 离线对象三方重放与删除保护（2026-09-14）

- 已登录工作区只在存在待同步修改时，把最后确认的完整云端快照及其 revision 写入本机 `_conuoSync` 元数据；同步完成后自动移除这份基线。读取时会用严格工作区 schema 校验它，并要求基线 revision 与待写 revision 完全一致。元数据在 IndexedDB 工作区记录中原子保存，加载后即从业务数据剥离，不进入云端 PUT、导出、检索或模型上下文；旧缓存缺少有效基线时继续进入显式冲突。
- CAS 冲突现在可用共同基线按资料、笔记和批注标识做保守三方重放。不同对象的单边新增、编辑或删除可以合并；同一对象双方不同编辑、删除对编辑、身份漂移、未知顶层变化和容量超限都会保留两个工作区副本，不猜测覆盖。
- 云端对资料的普通软删除会支配旧设备上的本机编辑：合并结果继续保留 `deletedAt`，因此资料不会复活，也不会回到资料库、搜索或 AI 范围。云端已经物理清除资料时，旧客户端不会重插资料，也不会写入失去资料/版本引用的批注或笔记引用。
- 当一侧软删除资料、另一侧离线新增或修改同一资料的 `source annotation` 人工文字时，三方重放会按批注标识与本次删除时间生成确定性的可恢复草稿；草稿精确保留资料、版本、原批注、原文选段、页码和时间上下文。它不会恢复资料，也不会进入普通搜索或 AI 证据范围。
- 阅读位置的页码、偏移和活动时间继续作为一个不可拆分候选；`lastReadAt` 仅供辨认，不参与自动胜负。双方都改变同一资料位置时，专用选择弹窗默认云端已确认位置，也允许逐项选择本机位置；提交前重新读取并核对确切云端 revision，所选结果先持久化到 IndexedDB，再以该 revision 做云端 CAS。
- 未选位置作为最多 8 条可恢复候选保留，并可在阅读器的资料操作菜单中再次切换；当前活动位置会同时回存，候选按完整阅读快照去重。解决期间会栅栏旧阅读计时器并在原阅读器内应用所选页码或正文偏移；资料换版、网页刷新和历史版本恢复不会继承其他版本的候选位置。
- 回收站现提供独立的可恢复草稿列表和完整预览；用户可以恢复整份资料、将文字另存为明确的人工笔记、复制文字，或经确认丢弃。恢复资料会原子处理该删除事件下的全部草稿；另存与丢弃只处理草稿及原批注，资料继续留在回收站。处理标记会区分“恢复时保留批注”和“另存/丢弃后移除批注”：后者即使资料后来恢复，也会继续压制更旧离线端带回的原批注；同一草稿的相反处置不会静默合并。旧版未记录处置的标记继续按保守语义读取。四个回收入口都只在该精确工作区快照写入本机 IndexedDB 后提示本机成功，云端完成状态仍由既有 CAS 同步状态显示。AT-20 的本地产品与数据链路已实现。

### 可恢复的文件导入队列与本机版本 CAS（2026-09-14，本地）

### 账号安全退出（ACC-03，2026-09-13）

- 工作区把退出风险分为已安全、正在保存、云端未同步、版本冲突和本机写入失败。只有当前账号的本机副本与云端副本都已确认时，才可直接调用本地 Auth 退出。
- 云端未同步时，账号面板会要求选择“等待同步后退出”或“保留本机草稿后退出”。前者先重新读取云端、执行现有 CAS 同步并确认完成；后者先将当前工作区及同步元数据写入该账号专属的 IndexedDB 键。若本机写入已确认、但云端请求仍在等待，仍可选择保留草稿；迟到云端结果不会再改写这个已冻结的账号会话。
- 正在写入、本机写入失败和未完成初始载入时，界面不提供虚假的“保留草稿”选项，也不会结束会话。冲突副本可以保存为当前账号的本机草稿后退出；其他账号和匿名工作区仍使用各自的缓存键。最终 Auth 调用前会锁住工作区，拒绝迟到编辑并中止问答、整理、导入等写入路径；Auth 失败则解除锁定，成功后显式切换到匿名工作区。

### 当前“问 AI”实际做什么

在本机工作区或服务端未配置生成模型时，程序在授权范围内查找相关文字，返回带引用的原文摘录，标记 `mode: extractive`。不把摘录称作模型推理，不编造摘要或答案。

服务端从规范化资料 RPC 取得关键词候选；开启语义能力且当前版本/profile 已发布时可混合召回，未就绪时保留关键词。总结继续按真实原文轮询采样，避免以相关性片段冒充全文。生成式模型返回内容须通过结构校验，引用绑定服务端原文片段，再复核当前账号、范围、版本及 AI 权限。生成结果标记 `mode: model`。当前仅完成一次不经过产品账本的真实 DeepSeek 图片输入冒烟测试；文本问答、整理和登录后的区域路由仍未完成供应商端到端验收，不能据此宣称事实正确性、摘要完整性、视觉解释或比较质量达标。

PDF 区域视觉是独立的、用户逐次触发的多模态范围：只发送当前选定区域的临时截图和本次问题，不把图片文字加入普通检索或后续整库上下文。解读、区域提问和一次性练习的结果均绑定发送时的资料、版本、物理页与归一化矩形；它们不能证明模型看过区域外内容或整份扫描资料。

“此资料 + 我的笔记”是唯一允许额外加入笔记正文的当前问答范围：它只从同一空间、同一资料、同一当前版本的已接受人工笔记中选择相关块，并把个人笔记依据与原始资料引用分开返回。原文结论不能由笔记支持；混合两类依据必须明确为推断。资料、版本、空间、笔记块或权限在生成中改变时，预览、缓存与完成结果都会被丢弃。

关闭全局 AI、撤销资料 AI 权限、删除资料或缩小提问范围都会影响新的检索。真实空间必须存在且未归档；虚拟收件箱只包含 `spaceIds` 为空的资料，不能用于绕过其他空间的范围检查。

“AI 整理”提供自动单份分析和手动跨资料主题生成的服务端链路。结果保留为建议，用户决定追加标签或逐个保存主题；不会自动移动资料或改名称。已有知识页的“更新建议”提供 KNO-03 的差异审核链路，只写入用户勾选的修改；完整且有原文依据的问答也可由用户追加到当前知识库的既有知识页，旧页先写入历史、引用去重并重编号、目标回到待审核。含个人笔记证据的回答不提供这一路径。“知识关系”提供 KNO-04 的双页关系维护与 AI 提案审核，详见 [关系说明](RELATIONS.md)。真实摘要、分类、主题、更新与关系判断质量仍未验证。普通搜索已包含笔记和已接受知识页；除受限的 document-notes 范围外，新 AI 检索不使用这些派生正文。
