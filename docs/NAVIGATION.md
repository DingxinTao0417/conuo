# 页面导航与路由约定

更新日期：2026-09-17。适用于当前响应式 Web 工作台的 hash 路由。

## 全局入口与知识库入口

侧栏主导航、Conuo 品牌和手机底部导航始终打开全账号视图。先进入任何知识库，再点击“学习概览”，都应显示“让知识，慢慢成为你的。”，地址为 `#home`。

知识库内部的“概览／资料／知识／问答”标签保留当前知识库。全局入口和库内标签分别调用显式全局导航与带空间 ID 的导航，不能依赖上一个页面残留的空间状态。

| 目的地     | 全局地址                                  | 知识库内地址                            |
| ---------- | ----------------------------------------- | --------------------------------------- |
| 学习概览   | `#home`                                   | `#home?space=<spaceId>`                 |
| 资料库封面 | `#library`                                | 不适用                                  |
| 资料列表   | `#library/all`                            | `#library/<spaceId>`                    |
| 知识页     | `#knowledge`                              | `#knowledge?space=<spaceId>`            |
| 我的问答   | `#questions?status=all`                   | `#questions?space=<spaceId>&status=all` |
| 我的笔记   | `#notes`                                  | `#notes?space=<spaceId>`                |
| AI 整理    | `#organize`                               | `#organize?space=<spaceId>`             |
| 任务中心   | `#tasks`                                  | 始终全局                                |
| 账号与设置 | `#settings/account` 或 `#settings/<pane>` | 始终全局                                |
| 回收站     | `#trash`                                  | 始终全局                                |

收件箱使用保留空间 ID `inbox`。概览页的“全部资料”打开当前范围的资料列表，清除此前残留的库筛选；侧栏“资料库”打开全局封面页。全局导航高亮和当前知识库高亮分别反映实际范围。

## 账号与设置入口

左下角账号入口和右上角头像统一打开 `#settings/account`，侧栏不再单列“设置”。该页面包含账号与设备、AI 与资料处理、云端资料与存储、阅读与同步、学习空间五组；密码、退出与注销仍通过账号组的“管理账号”进入原有面板。

账号入口始终清除旧知识库范围、关闭手机导航抽屉和资料详情，并使用一个浏览器历史项。设置子页之间仍按 `#settings/<pane>` 记录历史；旧 `#settings` 链接继续打开账号组。所有设置组均高亮账号入口。进入设置是纯导航，不因工作区正在保存而禁用；若账号访问已被注销流程阻断，账号入口仍打开原有恢复面板，不绕过访问保护。

## 地址与页面状态

- 用户切换页面和 AI 整理范围时记录浏览器历史；前进、后退和刷新恢复地址对应的页面及空间。
- 资料列表的查询、类型、时间、排序、标签、布局及跨库问答面板同步到地址。继续跨库问答时应用一份完整的全库默认视图，避免地址已经清空筛选、页面仍使用旧筛选。
- 知识页返回保留原搜索与审核筛选，问答列表恢复其状态筛选；从资料搜索结果打开笔记后，显式返回目标仍优先恢复原资料列表。
- 跨库置顶资料使用其真实所属空间；若当前空间确实包含该资料则保留当前空间，否则优先选择未归档的有效所属空间。没有有效所属空间时使用收件箱；仅关联已归档空间的资料仍保留其实际归属。
- 从原文保存笔记使用阅读资料的空间。退出笔记时，若原列表范围不包含该笔记，则转到笔记的有效所属空间；所属空间已不存在则返回全局列表。
- 离开资料列表时关闭临时详情侧栏，释放全局搜索快捷键。由“已识别内容”进入原文后返回，仍恢复原详情任务；浏览器同时发出 `popstate` 和 `hashchange` 时不重复关闭刚恢复的面板。

## 失效链接处理

资料和笔记 ID 按持久化规则安全解码；资料仅接受 `#source/<id>` 或 `#source/<id>/version/<versionId>`，笔记仅接受 `#note/<id>` 或附加 `relations`、`update`、`ask` 面板。缺少版本、错误编码及多余路径不能悄悄打开另一个版本或面板。

| 情况                             | 页面行为                                                               |
| -------------------------------- | ---------------------------------------------------------------------- |
| 空地址                           | 回到 `#home`                                                           |
| 未知页面或普通页面多余路径       | 回到 `#home` 并提示链接无效                                            |
| 畸形资料库／对照链接             | 回到 `#library` 并提示                                                 |
| 无效、缺失或已删除笔记           | 回到 `#notes` 并提示不可用                                             |
| 无效或缺失资料                   | 恢复可用的资料库返回视图并提示，沿用原阅读返回规则                     |
| 不存在的知识库                   | 在账号数据加载完成后，转为同页面的全局视图并提示；保留适用的查询与筛选 |
| 格式合法但内容不可用的对照／会话 | 保留现有不可用说明，不用其他资料或会话替代                             |

账号数据尚未加载完成时，不因空的初始快照判定知识库不存在。内容更新不重放页面导航；知识库 ID 集合变化时才重新检查空间链接。

## 验证范围

本轮新增 84 项回归，覆盖全局／库内导航、手机导航回调、直接链接、数据加载、前进后退、跨库问答筛选、跨库原文笔记归属与返回、详情侧栏和严格路径解析。完整测试为 242 个文件、4,152 项通过。

已在本地服务的真实登录页面核对两个知识库进入全局学习概览、库内概览、浏览器前进后退、全局问答／笔记／知识页／设置／任务中心／品牌返回、失效笔记回退及刷新恢复。没有发起模型请求或修改资料正文。构建、静态检查和进程状态见 [开发状态](IMPLEMENTATION_STATUS.md)，操作记录见 [design-qa.md](../design-qa.md)。
