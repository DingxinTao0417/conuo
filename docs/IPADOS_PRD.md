## 1. 产品目标与边界

iPad 与 iPhone 使用同一账号、业务对象与原生工程，但学习界面按当前可用窗口宽度自适应。iPad 的主要价值是让用户在原文旁持续记录和提问，不把手机页面简单拉宽，也不复制桌面全部侧栏。

本次已启动平板端设计开发。完整目标包含多栏阅读、触摸选段、键盘输入、手写批注与多任务学习；每项按下述阶段实现，不能以响应式 Web 截图或工程存在作为完成证据。原生 PDF、Pencil、笔迹云端版本与区域 AI 的实施合同见 [iPadOS PDF 手写阅读专项 PRD](IPADOS_HANDWRITING_PRD.md)。

- 云端是首个原生版本正式资料的权威来源，不新增 iPad 本地资料库或持久离线编辑承诺。
- 与 iOS 共用原生导航、认证与网络合同；平台能力独立适配并分别验收。
- 笔迹本身应可靠保存，识别只是后续可选能力；不会因识别失败而丢失笔画。
- 只对明确选定的原文或区域调用 AI；笔迹、识别结果与原始文献依据分开标记。
- 系统多窗口、分屏、拖放和 Pencil 分别验证，不能合称“iPad 已适配”后忽略差异。
- Apple 开发者资格、付费构建、签名、公证或商店发布仍需独立授权。

## 2. 核心任务

| 任务             | 典型操作                         | 用户可观察的结果                   |
| ---------------- | -------------------------------- | ---------------------------------- |
| 专注读一章材料   | 阅读原文、查看目录、添加少量批注 | 翻页、缩放和切换面板后位置不丢     |
| 原文旁提问       | 保持文档打开，右侧查看 AI 解释   | 对话范围可见，点引用定位正确原文   |
| 形成自己的笔记   | 左侧阅读，右侧编辑自己的理解     | 正文与引用云端保存，电脑可接续     |
| 对照两份资料     | 固定两个来源版本，独立翻页       | 不混淆两侧出处，比较问答只用这两份 |
| 使用 Pencil 思考 | 在文档页写画、移动或擦除笔迹     | 原始笔画保存，不依赖识别为文字     |
| 边看课程边收集   | 外部应用分屏、拖入文件或分享链接 | 显示导入确认和真实任务结果         |

任务完成率、错误恢复、引用定位和未保存内容丢失是首要验收指标。笔迹延迟、渲染帧率及大文件内存必须在确定设备和资料上实测，再建立发布门槛。

| P1 云端宽屏核心   | 登录、资料与知识阅读、问答、笔记、云端保存、宽窄布局接续               | 完整手写或复杂双文档比较已验收                 |
| P2 平板学习增强   | 原生 PDF 深度阅读、Pencil、双资料对照、系统分享 / 拖放及多窗口逐项落地 | 所有 Pencil 型号、所有 iPad 系统行为均兼容     |
| P3 学习与分发增强 | 笔迹解释、练习、通知、可选更多系统集成，签名与正式交付准备             | 未验收能力或收费服务已开放                     |

本轮工程起步优先覆盖真实登录、云端列表 / 知识阅读、单资料问答、文本笔记，以及 iPhone / iPad 自适应结构。完整 P1 仍需要读写、引用、异常和真机证据；P2 不提前标为完成。

分享与文件解析依赖 iOS PRD 的 I2 实现。原生阅读适配、笔迹数据和服务端写入接口必须做专项验证，不能假定 Web 解析器、批注表或 React DOM 组件能原样使用。

## 4. 布局系统

### 4.1 按窗口宽度适配

以下宽度为逻辑点设计基线，实际断点需在目标设备、动态字体和内容上复核。采用当前窗口宽度，不以设备型号或“是否横屏”直接决定布局。

| 可用宽度      | 主布局                                   | 阅读时的辅助区                         |
| ------------- | ---------------------------------------- | -------------------------------------- |
| 小于 760pt    | 单栏、紧凑顶栏、与手机同等完整的任务入口 | AI / 笔记全屏或底部面板，原文位置保留  |
| 760–1099pt    | 可收起导航 + 主内容；优先保证正文宽度    | 原文 + 一个辅助面板，空间不足时用抽屉  |
| 不小于 1100pt | 导航 + 原文 + 可调宽辅助区               | 可固定 AI 或笔记；双文档时收起多余导航 |

辅助栏最低可读宽度优先于“展示三栏”。动态字体变大、系统分屏变窄时，自动折叠辅助区但不关闭编辑；返回宽屏可恢复用户此前选择。

### 4.2 面板规则

- **P-LAY-01 / P0：** 初始内容铺满当前窗口，不保留空白的手机宽容器。
- **P-LAY-02 / P1：** 主文档只出现一次，AI、笔记、目录和批注使用明确可见的面板切换。
- **P-LAY-03 / P1：** 同时编辑笔记与问 AI 时保留各自输入；切换辅助内容不会丢弃另一个面板的未保存输入。
- **P-LAY-04 / P1：** 列宽调整、旋转和系统分屏后维持选中资料、版本与阅读锚点。
- **P-LAY-05 / P2：** 对照模式最多显示两份主资料；第三个 AI 区域宽度不足时改为抽屉。
- **P-LAY-06 / P1：** 不依赖悬停发现功能；触摸、鼠标、触控板和键盘均有可用入口。

## 5. 页面与导航合同

| 页面 / 逻辑路由     | 平板表现                                 | 主要返回行为                  |
| ------------------- | ---------------------------------------- | ----------------------------- |
| `learn`             | 最近学习、知识库与待处理任务，按宽度分列 | 始终为全局学习概览            |
| `library`           | 可切列表 / 网格、筛选区、资料详情        | 保留全局筛选和滚动位置        |
| `spaces/:id`        | 概览、资料、知识、问答分区               | 库内切换显式保留空间          |
| `sources/:id`       | 阅读器 + 目录 / 笔记 / AI 辅助区         | 还原进入前列表或引用位置      |
| `notes/:id`         | 阅读或编辑正文，来源侧栏可收起           | 未保存前有离开保护            |
| `knowledge/:id`     | 主题内容、来源、待审差异                 | 接受或弃用后返回原任务 / 列表 |
| `conversations/:id` | 问答与引用原文可并排                     | 不因打开引用改变提问范围      |
| `compare`           | 两份固定资料 / 版本，单独位置            | 窄窗改为分别打开入口          |
| `tasks`             | 全局导入、解析、整理和失败记录           | 不继承知识库隐藏其他任务      |
| `account`           | 列表 + 详情两栏或紧凑页面                | 所有设置从账号进入            |

深链接携带资料、版本和空间身份，认证后再解析；目标不可用时展示原因。不能只传“第 12 页”或标题来恢复引用。原生路由和 Web 路由使用集中转换，不各自猜测 ID。

- **P-NAV-01 / P1：** 全局入口与库内入口使用显式范围，防止“学习概览”显示上个知识库概览。
- **P-NAV-02 / P1：** 面板开关不改变主路由历史；打开新资料、笔记或对话才形成可理解的返回步骤。
- **P-NAV-03 / P1：** 删除、归档、权限改变或版本到期时页面重新校验，旧内容不继续被当作有效依据。
- **P-NAV-04 / P2：** 多窗口互不修改对方导航状态；账号和业务权限仍保持同一权威状态。

## 6. 原文阅读

- **P-RDR-01 / P1：** 单页 / 连续阅读、目录、页码、缩放和版本信息保持随时可达，宽屏不把工具散布到不可预测位置。
- **P-RDR-02 / P1：** 引用点击固定资料版本并定位；资料替换后旧引用不能悄悄指向新 PDF 同页。
- **P-RDR-03 / P1：** 原文阅读、解析文本和网页快照明确区分；简化排版不冒充原版。
- **P-RDR-04 / P2：** 双指缩放、单指滚动、文字选择、Pencil 书写有清晰模式，不同时争夺同一手势。
- **P-RDR-05 / P2：** 选择文本后的复制、批注、问 AI 菜单保持在可见区域，不被分屏边界或键盘遮挡。
- **P-RDR-06 / P2：** 扫描 PDF 可翻页；全文检索与文字选取不可用时提示，区域学习仍可明确发起。
- **P-RDR-07 / P1：** 前后台切换与旋转后从语义锚点恢复，不只恢复可能失效的滚动像素。
- **P-RDR-08 / P2：** 内存压力下释放远离视口的页面渲染；不清理正在编辑的批注或把渲染缓存当唯一数据。

原生 PDF 实现须实测中文、旋转页面、不同裁剪框、文字层和扫描件。渲染技术确定前，不能承诺所有 PDF 批注操作与 Web 完全一致。

## 7. 多文档对照

| 编号 / 阶段   | 规则                                         | 失败 / 降级                        |
| ------------- | -------------------------------------------- | ---------------------------------- |
| P-CMP-01 / P2 | 两侧明确资料名、版本和各自页码，独立翻页缩放 | 窄窗口提供分别打开的入口           |
| P-CMP-02 / P2 | 默认只从同一可访问知识库选两份有效资料       | 不静默把失效资料替换为其他文件     |
| P-CMP-03 / P2 | 比较问答限定恰好两份当前资料的有效版本       | 任一侧不可用于 AI 时停止比较问答   |
| P-CMP-04 / P2 | 两侧出处使用明确标签，引用回到对应一侧       | 历史版本已缺失则展示不可回跳原因   |
| P-CMP-05 / P2 | 用户手动固定对照状态，关闭其中一侧需明确     | 不把双资料请求降为单资料或全库请求 |

是否同步滚动作为后续增强，不是基本对照验收前提；不同资料的相同页码不表示内容对应。用户界面不得暗示未验证的自动对齐能力。

## 8. 笔记与知识页

- **P-NTE-01 / P1：** 原文旁可打开一篇笔记，标题、正文、依据和保存状态持续可见。
- **P-NTE-02 / P1：** 支持标题、段落、列表和引用的云端编辑；未知复杂块保持可读并保留，不被简单编辑器删除。
- **P-NTE-03 / P1：** 从原文摘录附带版本及锚点，用户自己的解释与引用文字区分。
- **P-NTE-04 / P1：** 切换 AI、旋转、分屏或隐藏面板时保留当前会话输入；关闭页面前处理未确认保存。
- **P-NTE-05 / P2：** 审核知识页采用原内容 / 建议内容 / 依据的可切布局，空间不足时按区块顺序展示。
- **P-NTE-06 / P2：** 接受建议核验基础版本，用户在其他端修改后提示冲突，不直接覆盖。
- **P-NTE-07 / P1：** 编辑器与 Web 数据互通，原生特有排版不能成为其他端无法读取的正文唯一表达。

笔记文本和手写批注是不同对象。将手写解释为文字时生成候选内容，用户确认后作为新的笔记编辑保存；不改写原始笔画。

## 9. Apple Pencil 与原始笔迹

### 9.1 书写交互

- **P-INK-01 / P2：** 用户明确进入标注模式；显示当前笔 / 荧光笔 / 橡皮擦 / 选择工具，退出后回到阅读操作。
- **P-INK-02 / P2：** 首期笔迹锚定 PDF 的确定页及版本；不将同坐标笔迹附着到后续新版本页面。
- **P-INK-03 / P2：** 笔画记录原始轨迹及必要样式，页面缩放 / 旋转后位置保持一致；位图预览不是唯一保存形式。
- **P-INK-04 / P2：** 支持撤销、重做、擦除和选择后的删除；每次操作只影响当前批注层，不擦掉 PDF 原件。
- **P-INK-05 / P2：** 支持手掌误触控制与手指导航；Pencil 不可用时仍能阅读、文字批注和键盘输入。
- **P-INK-06 / P2：** 特定 Pencil 手势按实际硬件能力启用，不用虚假开关暗示全型号支持。

### 9.2 保存与冲突

- **P-INK-07 / P2：** 每批笔画有稳定身份、资料版本、物理页、坐标系版本和提交状态；上传完成才标为云端已保存。
- **P-INK-08 / P2：** 云端存储原笔迹并可生成预览；新数据结构和写入接口需单独迁移、权限及容量验证。
- **P-INK-09 / P2：** 保存失败时，原始笔迹先写入账号隔离的本机恢复箱并明显提示“本机已保护 / 云端未确认”；恢复箱只保存未同步笔迹及提交清单，不构成完整离线资料库。
- **P-INK-10 / P2：** 并发新增笔画可按身份合并；同一笔画删除 / 变更冲突保留可判断结果，旧批次不复活删除内容。
- **P-INK-11 / P2：** 进入后台前必须尽力完成本机原子快照；云端上传仍只能在系统允许范围内继续，不能保证后台持续运行。只有服务端确认后才显示云端已保存。
- **P-INK-12 / P2：** 原文已删除或失去权限后停止上传并显示原因；必要时只允许用户明确导出自己的可恢复笔迹。

### 9.3 AI 与识别边界

P3 可将用户圈定的笔迹与必要原文区域一并预览后发送，分别标注“你的笔记”和“原始资料”。识别不确定的字符和模型推断不能作为文献事实；用户可以修改解释结果。

手写转文字、公式识别和自动评分分别建立样本验收。P2 保存原始笔迹成功不表示这些识别能力可用；默认不会自动发送整页笔迹给云端模型。

## 10. 区域学习与 AI 面板

- **P-AI-01 / P1：** 面板始终显示范围，用户在另一文档上操作时不能悄悄改变既有问题依据。
- **P-AI-02 / P1：** 回答结构化渲染，引用、推断和系统错误有明确样式；长回答不强行卷走正在阅读的位置。
- **P-AI-03 / P2：** 区域框选是独立工具；选区确认后才截图，预览后发送解读 / 问答 / 出题请求。
- **P-AI-04 / P2：** 坐标绑定物理页和归一化矩形，缩放、旋转、分栏偏移不会截取错误区域。
- **P-AI-05 / P2：** 有用户笔迹时明确选择是否一并发送；默认只含授权原文区域，不能包含旁边聊天或其他 App。
- **P-AI-06 / P1：** 后台中断后查询云端状态，不自动重发收费请求；停止、失败和完整回答分开保存。
- **P-AI-07 / P1：** 来源禁用 AI、删除或版本更新后重新检查；旧引用和已加载页面不构成继续调用的权限。
- **P-AI-08 / P2：** 区域一次性练习不冒充完整作答与复习记录；后续学习模块另行验收。

## 11. 系统多任务与外部输入

### 11.1 分屏、浮动窗口与多窗口

- **P-SYS-01 / P1：** 系统改变可用窗口大小时即时重排；键盘遮挡、系统安全区域和外部显示尺寸均计入可用空间。
- **P-SYS-02 / P2：** 多窗口各自保存导航、打开资料、位置和未发送问题；业务数据仍通过云端版本协调。
- **P-SYS-03 / P2：** 同一笔记被两个窗口编辑时使用同样的冲突规则，不能因为同一进程而绕过版本检查。
- **P-SYS-04 / P2：** 一个窗口退出账号或获知注销状态时，其他窗口立即停止该账号操作并释放访问。
- **P-SYS-05 / P2：** 窗口关闭仅关闭该学习上下文；未保存内容受保护，后台任务是否继续以云端状态为准。

实际支持哪些 iPadOS 多任务形态，以目标系统和开发构建验证后公布。可调整宽度的预览不是原生多窗口完成证据。

### 11.2 键盘、指针与拖放

- **P-INP-01 / P1：** 硬件键盘可完成搜索、页面导航、编辑、发送和关闭面板；快捷键展示帮助与触摸替代入口。
- **P-INP-02 / P1：** 中文输入法组合文字期间 Enter 不误发送；编辑器撤销不影响后台文档。
- **P-INP-03 / P2：** 从 Files 拖入文件先显示目标与确认；文件未复制 / 上传完成前不显示入库成功。
- **P-INP-04 / P2：** 从 Safari 拖入链接遵循 URL 导入合同；应用内部拖动只改变明确选中的对象关系。
- **P-INP-05 / P2：** 拖出原件或导出笔记由用户主动触发，临时文件有生命周期，目标应用接收后不承诺可撤回。
- **P-INP-06 / P1：** 指针命中反馈与键盘焦点可见；不要求触控板悬停才能找到删除、分享或保存。

## 12. 数据与保存状态

继承 iOS PRD 第 7 节：正式业务在云端，认证材料存入系统安全存储，导入 / 导出使用有限生命周期的系统临时文件。为避免连续手写在杀进程、断网或上传失败时丢失，iPad 仅对尚未云端确认的原始笔迹和提交清单提供账号隔离的持久恢复箱；它不是可浏览的离线资料库，具体生命周期与隔离规则见 [手写专项 PRD 第 13 节](IPADOS_HANDWRITING_PRD.md#13-本机恢复与保存状态机)。

| 状态       | 含义                           | 用户可采取动作              |
| ---------- | ------------------------------ | --------------------------- |
| 正在编辑   | 当前输入尚在内存，未获云端确认 | 继续编辑或主动保存          |
| 本机已保护 | 未同步笔迹已原子写入应用沙盒   | 等待同步、立即重试或导出    |
| 正在保存   | 已发起本次版本写入，结果未确认 | 等待，避免重复提交          |
| 云端已确认 | 服务端已确认对象与版本         | 换设备接续                  |
| 保存失败   | 本次输入仍可能只在当前会话     | 重试、复制 / 导出、取消离开 |
| 版本冲突   | 云端内容在本次基础版本之后改变 | 比较并合并、保留独立副本    |

资料下载到阅读器临时目录只服务当前阅读，不形成用户可管理的“离线下载”入口。低内存或系统清理临时文件时重新联网获取，不能误报资料已从云端删除。

## 13. 端到端学习任务

### 13.1 读原文、问 AI、形成笔记

1. 从学习页打开同一知识库中的 PDF，恢复已确认位置。
2. 展开 AI 面板，选择当前资料范围并提问。
3. 点回答引用，原文定位同时保留问题与回答滚动位置。
4. 切换笔记面板，写自己的解释并附原文引用。
5. 云端确认后在 Web 验证内容，iPad 缩成窄分屏仍可继续编辑。

### 13.2 手写阅读与重新打开（P2）

1. 进入 PDF 标注模式，用 Pencil 画线和书写，再撤销 / 重做一次。
2. 放大、旋转、切页返回，确认笔迹与原文对应位置。
3. 等待云端确认，关闭应用后重新打开并验证原笔迹。
4. Web 或其他端尚不支持编辑时至少显示可识别预览和类型说明，不能丢弃笔迹对象。
5. 网络失败时保留明确未确认状态，用户决定重试或导出。

### 13.3 两份资料比较（P2）

1. 选择两份同库当前版本，左右各定位到目标页。
2. 发起仅包含这两份资料的比较问答，区分两侧来源。
3. 切换系统分屏导致宽度不足时，保留两份身份并提供分别打开。
4. 其中一份被 Web 删除，当前比较立即失效并说明原因。

### 13.4 多窗口并发与退出（P2）

1. 窗口 A 与 B 同时编辑一篇笔记，先后提交。
2. 后提交窗口获得冲突，保留其输入，不覆盖另一窗口正文。
3. 在 A 退出账号，B 的在途结果不得继续展示原账号资料。
4. 再登录其他账号，无旧笔记、未发送问题或分享内容串入。

## 14. 异常状态

| 触发                  | 必须呈现与保留                               | 恢复                           |
| --------------------- | -------------------------------------------- | ------------------------------ |
| 窗口突然变窄          | 主文档和编辑内容保留，辅助面板改为可打开入口 | 放大后恢复面板偏好             |
| 低内存导致重载        | 云端已确认内容不丢；未确认输入不伪称已保存   | 拉取云端并说明未完成操作       |
| 原生 PDF 打不开       | 错误与文件身份，不错误展示解析全文成功       | 重试、阅读已解析文本或导出原件 |
| Pencil 不可用 / 断连  | 阅读与文字批注仍可用；已完成笔迹保持         | 重连或使用已支持替代输入       |
| 笔迹上传失败          | 当前会话笔画与未保存状态                     | 重试、明确导出                 |
| 外部拖入失去文件权限  | 不创建假成功资料，不删除源文件               | 重新通过系统选择器授权         |
| AI 区域无效或版本变化 | 不提交，保留问题文本                         | 回到正确版本重新框选           |
| 源资料已彻底删除      | 不复活旧版本、不继续 AI                      | 导出本人可恢复内容或返回资料库 |
