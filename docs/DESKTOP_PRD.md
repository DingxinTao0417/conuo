## 1. 决策与适用边界

本次用户已要求开始其他端的设计与开发，并明确电脑端功能应与网页端基本一致。桌面版沿用 Web 的业务概念、内容结构、主要导航和已验证交互，不另造一套资料管理产品。平台差异体现在窗口、键盘、系统文件、本地存储和安装维护上。

主 PRD 中“只做 Web、其他端未启动”的旧排期由本次决定更新；共用业务规则仍以主 PRD 为基线。实际已实现范围必须看实施状态，文档中的“必须”表示交付要求，不表示代码已经具备。

- **确认方向：** Electron + React + TypeScript，优先复用 Web 的学习工作台。
- **确认存储：** 桌面完整目标为本地与云端共存；Web 继续只有云端正式存储。
- **起步实现：** 先建立安全桌面宿主并验证云端工作台；本地数据库与同步引擎分阶段落地。
- **共同后端：** 继续使用 Next.js API、Supabase Auth / 数据库 / 私有 Storage。
- **发布边界：** 本地开发、构建、签名、公证、分发、商店发布分别记录，不相互替代。
- **本次不自动执行：** 付费签名、付费构建、商店提交、生产数据库变更和生产发布。

## 2. 用户目标与成功条件

| 任务                      | 用户可观察的成功结果                                         | 主要需求           |
| ------------------------- | ------------------------------------------------------------ | ------------------ |
| 从 Web 转到电脑客户端学习 | 登录后看到同一份资料，在相同位置继续；没有额外迁移向导       | D-ACC-01、D-SYN-01 |
| 长时间阅读和整理          | 文档、笔记与 AI 的操作位置稳定；鼠标与键盘均可完成           | D-RDR-01、D-NAV-03 |
| 收集本机资料              | 选择或拖入文件，明确目标知识库，每份文件有独立结果           | D-IMP-01           |
| 暂时离线仍能学习          | 已下载资料可打开，修改有可靠本地保存状态，恢复网络后处理同步 | D-LOC-02、D-SYN-02 |
| 保存敏感的本机资料        | 可建立仅本机知识库，未选择上传时原文不进入云端或 AI          | D-LOC-01、D-AI-02  |
| 换电脑或退出账号          | 已同步内容可接续；未同步内容先处理，账号之间无资料串读       | D-ACC-03           |

性能指标在代表性资料与设备上测量，不在没有实测时承诺启动时间、内存或可支持页数。首轮验证必须记录设备、构建版本、资料大小和实际结果。

## 3. 分期与交付门槛

| 阶段              | 必须完成                                                                        | 不属于该阶段已交付                             |
| ----------------- | ------------------------------------------------------------------------------- | ---------------------------------------------- |
| D0 工程起步       | 可运行宿主、环境识别、受限导航、窗口基本操作、加载与故障页、构建说明            | 本地资料库、离线编辑、完整业务验收、正式安装包 |
| D1 云端工作台     | Web 核心功能逐项验收、账号隔离、文件导入导出、阅读与 AI、恢复登录、窗口关闭保护 | 仅本机知识库、持久离线包、多窗口独立编辑       |
| D2 本地与云端共存 | 本地工作区、明确下载、持久待同步队列、冲突处理、账号退出保护、迁移与恢复        | 本地模型、自动文件夹监控、任意网站自动采集     |
| D3 系统增强与分发 | 受限内置浏览、系统文件打开、平台签名和升级验证；按实际优先级分项交付            | 不保证所有增强同时完成，不自动开放商店分发     |

D0 可暂时在受限宿主中加载批准的云端 Web 入口以验证复用；这仍依赖网络，不能称为桌面离线版。D2 必须有打包的本地渲染入口和桌面存储适配，不能将远程页面缓存冒充本地工作区。

D1 验收以冻结的 Web 版本建立差异表。Web 新增能力先标注“待同步”，禁止通过隐藏核心入口宣称功能已对齐。桌面专用功能尚未交付时显示准确说明或不提供操作按钮。

## 4. 信息架构与页面映射

| 页面              | 路由语义                       | 主要操作与上下文                             |
| ----------------- | ------------------------------ | -------------------------------------------- |
| 登录 / 恢复账号   | `auth`，不含业务快照           | 登录、注册、找回；成功后验证返回目标         |
| 学习概览          | `home`，全局                   | 最近学习、待处理任务；不能继承上次知识库过滤 |
| 资料库            | `library` + 可选空间与筛选     | 文件、版本、标签、排序、批量操作             |
| 知识库概览        | `home?space=<id>`              | 明确展示当前知识库；切换标签仍保留该范围     |
| 我的笔记 / 知识页 | `notes` / `knowledge`          | 列表、编辑、历史、审核、引用                 |
| 我的问答          | `questions` + 明确范围         | 继续对话、查看失败尝试、回跳来源             |
| 阅读器            | `source/<id>` + 版本及返回目标 | 单页 / 连续阅读、选段、批注、区域学习        |
| 双资料对照        | 现有 comparison 合同           | 两份固定版本、各自位置、受限比较问答         |
| 任务中心          | `tasks`，全局                  | 导入、解析、整理进度与失败恢复               |
| 回收站            | `trash`，全局                  | 恢复、查看影响、确认彻底删除                 |
| 账号与设置        | `settings/<pane>`              | 共用账号设置及桌面新增“本机存储”分组         |
| 本机工作区管理    | D2 新增，设备级                | 切换本机库、下载管理、待同步项、导出         |

表内是逻辑路由，不强制把 Web hash 直接作为操作系统协议。来源与版本的解析规则复用已有合同；不允许凭文件名猜测目标。登录回跳、外部链接和历史恢复均校验目标归属。

### 4.1 导航要求

- **D-NAV-01 / D1：** 全局入口清空空间继承，库内入口明确携带空间；前进、后退、重开后结果一致。
- **D-NAV-02 / D1：** 已删除、越权、失效版本显示原因和安全返回入口，不残留上一份资料内容。
- **D-NAV-03 / D1：** 所有快捷键均有菜单或按钮等价入口；输入框中的常用编辑快捷键不被全局劫持。
- **D-NAV-04 / D1：** 返回列表恢复筛选、选中项与滚动；从引用打开原文可返回原对话位置。
- **D-NAV-05 / D2：** 本机库与云端知识库有持续可见的归属标签，搜索和 AI 范围不隐式跨越。

### 4.2 视觉与布局

采用 Conuo 现有 Web 品牌、字体层级、色彩、间距和语义图标。左侧导航、中间内容、可收起 AI 面板构成基本布局；窗口变窄时折叠辅助区域，正文不被固定栏挤成不可读宽度。

标题栏不展示密钥、完整文件路径或内部任务标识。保存状态用“本机已保存”“等待同步”“云端已确认”“需要处理”表达不同事实；D1 只显示已实现的云端状态。

空状态提供具体入口；失败状态保留任务标题及操作结果。危险操作不能只靠颜色区分。高对比度、键盘焦点和系统缩放应覆盖文件列表、阅读工具、弹窗和编辑器。

## 5. Web 功能对齐要求

| 编号 / 阶段   | 桌面要求                                                       | 对齐依据 / 额外验收                       |
| ------------- | -------------------------------------------------------------- | ----------------------------------------- |
| D-PAR-01 / D1 | 空间创建、关联、归档、标签、搜索和批量操作保持 Web 语义        | 主 PRD SPC、SRC；全局与库内边界           |
| D-PAR-02 / D1 | 支持 Web 已验收的 PDF、文本、Markdown、DOCX 和公开网页导入路径 | IMP；不能承诺未验证格式或完整 Office 排版 |
| D-PAR-03 / D1 | 原文件版本、历史版本、引用状态与阅读位置可跨端恢复             | RDR；旧引用不能换成当前版本               |
| D-PAR-04 / D1 | 笔记、知识页、历史、差异与人工审核保留现有模型                 | NTE / KNO；不覆盖人工编辑                 |
| D-PAR-05 / D1 | 问答、停止、重试、结构化渲染和引用回跳与 Web 一致              | ASK；相同范围的服务端复核                 |
| D-PAR-06 / D1 | PDF 区域截图解读、提问、出题复用明确发送和版本绑定规则         | ASK-08；不扩展为 OCR 全文索引             |
| D-PAR-07 / D1 | 任务取消、失败重试、删除影响预览、导出恢复齐备                 | DAT / IMP；终态与服务端一致               |
| D-PAR-08 / D1 | AI 开关、额度、存储、账号注销与退出保持 Web 行为               | ACC / DAT；客户端不能绕过服务端约束       |

“基本一致”允许原生文件选择、菜单与窗口替代浏览器操作，但不允许改变账号隔离、版本依据、删除语义或云端确认标准。

## 6. 账号、环境与授权

- **D-ACC-01 / D1：** 云端模式必须登录；登录失败、未确认邮箱、恢复链接过期、刷新失败分别给出可恢复提示。
- **D-ACC-02 / D1：** 原生安全存储方案完成前，不把凭据写入普通配置文件；不在日志或导出中包含会话凭据。
- **D-ACC-03 / D2：** 切换账号前列出该账号未同步修改，可选择完成同步、导出后移除或取消退出；不静默丢弃。
- **D-ACC-04 / D1：** 测试和生产使用分离的配置及数据目录；测试版本可见环境标识，不能偷偷切换后端。
- **D-ACC-05 / D1：** 邮件、OAuth 或深链接回调绑定原始事务，拒绝任意外部重定向；冷启动和已启动各验收一次。
- **D-ACC-06 / D2：** 本机库不强制登录；进入云端功能时才登录。账号退出不能把其云端副本变为匿名资料库。

远程 Web 入口起步阶段可以使用该宿主的隔离会话，但必须单独验证 Cookie 生命周期、退出和重启，不能用浏览器已通过的登录验收代替桌面验收。

## 7. 文件收集与内置浏览

### 7.1 文件导入

- **D-IMP-01 / D1：** 支持文件选择与拖入，预览名称、大小、类型、目标空间和重复判断；逐项取消、重试、定位成功资料。
- **D-IMP-02 / D1：** 本机文件默认复制进入受管理的导入流程，不改变或删除用户原文件；上传开始不等于入库完成。
- **D-IMP-03 / D1：** 权限拒绝、文件消失、零字节、损坏、超额、网络中断分别呈现；其他成功项目保持成功。
- **D-IMP-04 / D2：** 仅本机目标写入成功即显示“本机已保存”；云端目标同时显示上传、解析和同步各阶段。
- **D-IMP-05 / D3：** 系统“打开方式”触发时显示导入确认；第二次启动复用当前实例或显式新窗口，不重复导入。
- **D-IMP-06 / D2：** 文件夹批量导入只读枚举当前选择；先展示数量和不支持项，不递归追踪任意链接或后台监控。

### 7.2 网页收集

D1 复用 Web 的 URL 快照流程和原站外部打开。D3 的独立内置浏览器增加地址栏、前进后退、刷新、外部打开以及“保存到知识库”。当前网页与已保存快照有明显区分。

- **D-WEB-01 / D3：** 外站浏览进程不具有主应用文件与账号 API 权限；网页中的文字不构成宿主指令。
- **D-WEB-02 / D3：** 保存前展示标题、最终地址、目标库和可提取范围；失败可仅保存链接或手动导入。
- **D-WEB-03 / D3：** 第三方站点 Cookie 留在该设备独立会话，不随知识库同步；不采集站点密码。
- **D-WEB-04 / D3：** 下载、弹窗、文件访问和外部协议逐类处理，不把任意链接直接交给系统执行。
- **D-WEB-05 / D3：** 登录、验证码、付费墙及不可提取内容如实提示；不绕过访问控制，不承诺所有站点兼容。

## 8. 阅读、编辑与 AI

- **D-RDR-01 / D1：** 单页 / 连续模式、目录、页码、缩放、选段、标注、版本和对照保持 Web 能力；窗口改变不重置页码。
- **D-RDR-02 / D1：** 文本选取与拖动窗口、区域截图手势隔离；截图仅包含用户选定的文档区域。
- **D-RDR-03 / D1：** 键盘翻页、查找和菜单操作有焦点边界；编辑笔记时不会意外翻动后台文档。
- **D-EDT-01 / D1：** 编辑器格式、引用、历史与 Web 可互通；粘贴内容清理可执行部分，不引入客户端专用不可读正文。
- **D-EDT-02 / D2：** 编辑先持久写入本机，再排队同步；本机落盘失败不得展示保存成功或退出提示消失。
- **D-AI-01 / D1：** 仅访问既有受鉴权 API；模型密钥不进入客户端，响应依据和额度由服务端约束。
- **D-AI-02 / D2：** 本机库的资料默认不发送云端；首次选择云端 AI 时明确展示发送对象与范围，未确认不提交。
- **D-AI-03 / D2：** 本机库尚未接入有权限隔离的临时 AI 上下文接口前，只提供显式复制到云端库后提问；不偷偷上传。
- **D-AI-04 / D2：** 离线时保留当前问题输入，明确 AI 需要网络；恢复网络不自动发送，避免意外消费额度。

## 9. 本地与云端的数据规则

### 9.1 三种不同对象

| 对象               | 权威存储                            | 联网行为                       | 清除与迁移                             |
| ------------------ | ----------------------------------- | ------------------------------ | -------------------------------------- |
| 仅本机知识库       | 本机受管理数据库与原件目录          | 不自动同步，不自动调用云端 AI  | 用户导出备份；删除前说明不可由云端恢复 |
| 云端库的设备副本   | 云端版本 + 本机明确保存的待同步修改 | 显式下载，在线时同步已授权修改 | 清除下载不删除云端；待同步内容先处理   |
| 渲染和传输临时文件 | 无独立资料权威性                    | 仅用于当前读写操作             | 按生命周期释放，不能当作离线副本       |

- **D-LOC-01 / D2：** 创建知识库时明确选择“仅本机”或“云端”；后续切换采用有预览的复制 / 迁移任务，原库不自动删除。
- **D-LOC-02 / D2：** 下载必须绑定资料、版本和哈希，所有原件完成并校验后才显示“离线可用”。
- **D-LOC-03 / D2：** 元数据、正文变更和待同步记录在本地事务中提交；崩溃后能还原未确认操作。
- **D-LOC-04 / D2：** 本机工作区有格式版本和迁移备份；迁移失败保持原库可恢复，不直接重建空库。
- **D-LOC-05 / D2：** 磁盘不足时停止新写入，保留旧内容；清理候选不包含未同步修改和仅本机唯一原件。
- **D-LOC-06 / D2：** 应用内部账号目录隔离；系统文件权限保护不等同于全盘加密，未实现应用级加密前不作该承诺。

### 9.2 同步与冲突

- **D-SYN-01 / D1：** 云端确认后其他端才能承诺可见；响应丢失先读取权威状态，不盲目重复追加。
- **D-SYN-02 / D2：** 每次修改绑定账号、对象、基础版本和幂等身份；重启、网络重试不重复创建正文或附件。
- **D-SYN-03 / D2：** 正文并发保留两份差异，由用户合并或择一；不能用最后写入覆盖未看到的内容。
- **D-SYN-04 / D2：** 阅读位置冲突保留选择入口；批注按对象身份合并，删除使用可追踪标记，旧端不能复活。
- **D-SYN-05 / D2：** 云端已彻底删除的资料停止同步和 AI；旧本地编辑只能明确导出为独立内容，不能复建旧身份。
- **D-SYN-06 / D2：** 重新联网先校验会话与删除状态再发送队列；账号失效时暂停原账号队列，不转交当前账号。
- **D-SYN-07 / D2：** 账号注销在联网获知后封锁并处理其副本；不能承诺远程擦除永不联网设备或用户导出的文件。

当前 Web 的整工作区快照及 revision 合同可以作为接入起点，但 D2 必须验证本地变更如何映射到该合同；只有数据库文件而没有冲突与删除处理不能通过 D2。

## 10. Windows 专项需求

| 编号 / 阶段   | 需求                           | 验收要点                                            |
| ------------- | ------------------------------ | --------------------------------------------------- |
| D-WIN-01 / D0 | 原生最小化、最大化、还原和关闭 | 多显示器、任务栏激活、窗口重开不出现在屏幕外        |
| D-WIN-02 / D1 | Ctrl 系列快捷键与常规菜单      | Ctrl+F 在当前文档查找；复制、粘贴、撤销尊重编辑焦点 |
| D-WIN-03 / D1 | 文件路径与系统缩放             | 中文名、空格、长路径、125% / 150% / 200% 无核心遮挡 |
| D-WIN-04 / D2 | 休眠、锁屏、唤醒与网络切换     | 暂停请求可恢复，失效凭据不被循环重试，编辑不假保存  |
| D-WIN-05 / D3 | 可验证的安装 / 卸载 / 升级     | 安装位置和数据位置分离；卸载是否保留资料明确选择    |
| D-WIN-06 / D3 | 文件关联与通知                 | 用户主动启用；不抢占系统默认关联，不默认常驻托盘    |

Windows 架构与最低系统版本以实际所选 Electron 版本、依赖和目标设备测试后锁定。开发启动成功不代表安装包已通过系统安全提示与升级验证。

## 12. 典型端到端任务

### 12.1 从网页接续阅读

1. Web 保存一条笔记与阅读位置并确认云端成功。
2. 桌面登录同一账号，拉取权威数据，打开“继续学习”。
3. 校验资料与版本，定位页面；打开笔记并点击引用。
4. 桌面修改笔记，云端确认后 Web 刷新可见相同版本。
5. 若云端拉取失败，停留可重试页；不能初始化空资料库覆盖原内容。

### 12.2 本机文件到知识页

1. 拖入两份支持文件，选择目标库，确认重复项处理。
2. 分别展示上传、解析、索引状态；失败一项不隐藏另一项成功。
3. 打开成功资料，发起有范围的问答，核对原文引用。
4. 生成知识页建议，编辑后接受；Web 验证正文与依据一致。

### 12.3 离线编辑后发生冲突（D2）

1. 明确下载资料并等待完整校验；断网后阅读、添加批注与笔记。
2. 另一端在线修改同一笔记，然后当前设备恢复网络。
3. 展示“本机已保存，存在同步冲突”，比较基础、本机和云端内容。
4. 用户合并后以新版本保存；两份原始候选保留至确认完成。
5. 重启客户端再次验证，队列为空且云端无重复笔记。

### 12.4 退出与关闭

D1 关闭时若仍有未获云端确认的修改，先提示等待、导出或取消；不能直接宣称已保存。D2 已本机持久保存的改动可关闭并下次继续同步，但退出账号须单独处理未同步副本和访问保护。

## 13. 异常状态与恢复入口

| 场景                   | 必须呈现                                  | 允许操作                 |
| ---------------------- | ----------------------------------------- | ------------------------ |
| 首次启动离线           | 云端工作台需要网络；D2 可进入已存在本机库 | 重试、进入明确本机库     |
| 服务不可达 / 超时      | 保留现有读取内容，未确认写入状态可见      | 重试读取、导出未保存内容 |
| 会话过期               | 操作暂停，不清空正文编辑                  | 登录后复核原账号与版本   |
| 配额不足               | 展示哪项未执行，已保存原件保持准确状态    | 管理存储、稍后重试       |
| 原件校验失败           | 不标离线可用，不以破损文件覆盖可用版本    | 重新下载、查看错误       |
| 本机数据库损坏         | 不删除原文件或自动创建同名空库            | 从备份恢复、导出可读数据 |
| 云端删除与本机编辑相遇 | 不复活原资料，保留可恢复编辑说明          | 导出、查看删除影响       |
| 升级失败               | 保持旧版本和用户数据可恢复                | 重试、回退程序版本       |
