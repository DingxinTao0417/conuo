日期：2026-09-21。目标是让联网桌面版可靠承接 Web 核心功能；需求见 [桌面 PRD](DESKTOP_PRD.md)。当前 **D1 仍在进行中**。

## 版本与环境

- 本地桌面版本：`0.1.4`，Windows x64 未签名便携预览包；客户端改动未提交、推送或发布。
- 便携包：`Conuo-Preview-0.1.4-win-x64.exe`，100,398,258 字节；SHA-256 为 `410EE88223E361574269BA4900924C15B499794BF391738FBF75E1EF0CA5426B`。ASAR 内主进程、策略、侧栏适配、preload 与标题栏 HTML/CSS/JS 和当前编译产物一致，不包含 `.env`。旧预览包保留用于回退。
- 实际接口：独立 staging，探针核对 Git SHA `e7057a46a21f26ae1f4df376961eaa683dfeb09d`。
- 会话验证：创建隔离 Electron 测试 profile，使用已存在的 QA 账号，不读取用户日常浏览器或桌面 profile，不创建账号、不使用管理员身份访问业务数据。
- 保持生产环境、Supabase schema、邮件配置和自然 Cron 夹具不变；未安装或运行本地 PostgreSQL，未调用 cleanup API。

## 已修复与实现

1. 在下载或连接面板执行前进/后退时，恢复工作区可见状态；切回工作区恢复键盘焦点，隐藏工作区时焦点移至可见的本地面板。
2. 重启保留窗口位置、大小、最大化与缩放。外接屏断开、分辨率改变或配置文件损坏时回到当前可用屏幕范围，不让标题栏和底部操作区消失在屏幕外。
3. 新增 F5 重新加载和编辑区原生右键菜单。重载复用现有未保存内容保护，不新增远程 Node/IPC 权限。
4. 窗口偏好只保存界面尺寸和缩放，独立于业务数据。未增加本地资料库、文档路由持久化或后台文件同步。
5. `0.1.2` 将传统菜单和导航工具条收进 40px 浅灰标题栏，使用 Conuo 的 `#f7f7f8` 辅助底色；Windows 原生窗口按钮同步背景色，Web 内容从标题栏下方开始。原生应用菜单在窗口显示前隐藏，避免启动闪出旧菜单。菜单 IPC 仅允许四个固定入口与受限坐标，不扩大远程网页权限。
6. 当前 `0.1.4` 将顶部最左侧 Logo 换成主侧栏显示/隐藏图标，保留文件、编辑、视图、帮助四个菜单；`Alt+F` 与 `F10` 进入文件菜单。“学习概览”仍可从文件菜单或 `Ctrl+Shift+H` 进入。侧栏用 `Ctrl+\` 切换，macOS 对应 `Cmd+\`。固定样式只匹配主侧栏及其遮罩；正文自动扩展，目录和 AI 面板不被隐藏，业务草稿不被重置。桌面缩放进入手机断点时侧栏以文档流面板显示，网页重复导航按钮隐藏。偏好在同一进程内刷新和导航后保留，重启恢复展开。
