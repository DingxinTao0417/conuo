# PDF 阅读模式

更新日期：2026-09-24。范围：当前 Web PDF 阅读器。

## 使用方式

PDF 原页阅读提供“单页／连续滚动”切换。宽屏和平板入口位于文档工具条，手机通过常驻工具条中的“阅读工具”展开；解析文本仍以规范化正文连续阅读，不生成虚构的物理页。

- **单页：** 只显示当前物理页，使用上一页、下一页或页码跳转。
- **连续滚动：** 所有物理页纵向排列，向下或向上滚动时更新当前页码；页码输入、前后页和引用定位仍可直接导航。
- 模式切换尽量保留当前页内的视口位置，不重新下载原件。模式属于当前阅读器会话显示状态，刷新后默认单页；已经保存的物理页进度从云端恢复。
- 页码输入完成后按 Enter 或移开焦点跳转，按 Esc 取消编辑；清空和非法输入不跳页。输入超过总页数的正整数会到末页，同页按 Enter 可重新定位到页首。
- 手机工具条滚动时保持可见，前后页与页码常驻；缩放和其他工具按需展开。按 Esc 可收起扩展工具；打开目录或标注时收起扩展操作，标注面板也可直接关闭并返回阅读。
- PDF.js 书签会在原始 PDF 打开后懒加载为资料目录；目录项保留最多 6 层层级，点击后跳到书签页。读取到的目录按 `source_id`、`version_id` 单独保存，属于可重算的派生导航，不修改不可变版本正文。没有书签时，新导入任务会按相对字号识别有限的标题目录；保存云端前不会把它混入工作区快照。

## 渲染与进度

每个资料版本共用一份 PDF.js 文档。连续模式为全部物理页保留占位，实际绘制视口附近最多 5 页；远页释放 Canvas 像素与文字层。每页加载或文字层失败分别展示状态，重试沿用原件打开流程。尚未加载页的占位尺寸为估计值，第一次呈现后的真实页尺寸可能调整布局，不承诺所有页提前精确排版。

当前页码反馈与显式导航使用不同信号：自然滚动只更新页码，显式页码跳转或引用定位才请求定位。宽度、缩放和模式变化使用可用页内比例重新定位，避免连续反馈把页面反复滚回。

真实阅读活动使用已有 `readPage`／`lastReadAt` 合同。滚动页变化先合并 400 ms，再按已有 15 s 活动节流提交；离开阅读器时提交尚未报告的最后物理页，父工作区负责云端保存确认。显示模式切换本身不制造阅读活动。历史版本可浏览和切换模式，但不更新当前资料的进度或最近阅读时间。

## 引用、批注与区域学习

- 每个原始页 Canvas 与已就绪 TextLayer 都携带实际物理页身份，并绑定资料及版本。
- 连续视图选中非当前页文字时，摘录、笔记引用与批注使用选区所在页；跨页原生选区不能静默归到当前页，需要分开选择。
- 页身份不要求整页解析文字已经保留；保存高亮的精确原文偏移仍须独立核对完整原文投影。重复句子按物理页或确切原文锚点定位，缺失或尚未呈现页面不回退到相似文字。
- 已经定位的批注或引用不会因为附近页面再次绘制而重复自动滚动。页内搜索以当前已呈现的物理页文字为范围，全文搜索使用解析文本。
- 区域截图入口只绑定当前物理页。页面、模式和截图上下文改变后，未确认框选失效；晚到的旧编码结果不能进入新的选择。切换模式不会自动请求模型或上传截图。

## 验证记录

自动回归覆盖模式切换、物理页导航与进度、云端元数据更新、历史只读、非当前页重复文字摘录、多层批注证明、Canvas／TextLayer 生命周期以及截图隔离。本轮使用隔离六页自编样本核对实际页面，操作不导入账号或调用模型；最终结果与临时样本清理见[开发状态](IMPLEMENTATION_STATUS.md)和[界面验收](../design-qa.md)。

目录 API 只接受当前账号仍保留的资料版本；每项标题最多 200 字、层级 1–6、页码 1–100000，目录最多 1000 项。历史版本清理会级联移除对应目录；目录读取或保存失败不阻断原始 PDF 阅读。该能力不实现原生桌面或移动客户端；旧匿名副本的缺原件确认和迁移仍按[Web 存储政策](WEB_CLOUD_STORAGE.md)独立处理。
