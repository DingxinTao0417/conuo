## 导数定义

函数在一点的导数，描述该点附近函数值相对于自变量的瞬时变化率，也就是曲线在该点的切线斜率。若极限存在：

```text
f'(a) = lim_{h -> 0} [f(a + h) - f(a)] / h，h != 0
```

分式是两点之间的割线斜率；让 h 趋近 0，得到切线斜率。

## 固定例子：y = x²，x = 2

函数为 f(x) = x²。当 x = 2 时，f(2) = 4，因此切点是 P(2, 4)。

```text
[f(2 + h) - f(2)] / h
= [(2 + h)² - 4] / h
= (4h + h²) / h
= 4 + h，h != 0
```

令 h 趋近 0，得到 f'(2) = 4。因此导数和切线斜率都为 4；点的纵坐标也是 4，但纵坐标与斜率是不同含义。

## 切线方程与图像

使用点斜式：y - 4 = 4(x - 2)，整理为 **y = 4x - 4**。切线经过 P(2, 4)，与 y 轴交于 (0, -4)。当 x = 3 时，切线上的 y = 8，而抛物线上的 y = 9。

图中蓝色曲线表示 y = x²，橙色直线表示 y = 4x - 4，紫色点表示 P(2, 4)。两者之差为 x² - (4x - 4) = (x - 2)²，因此抛物线不低于这条切线，且仅在 x = 2 处相等。

## QA 核对用练习

1. 问：切点、导数与切线方程分别是什么？答：P(2, 4)、4、y = 4x - 4。
2. 问：h = 0.1 时割线斜率是多少，是否已等于导数？答：4.1；尚未等于导数 4。
3. 问：切线在 x = 3 时的纵坐标是多少？答：8。
4. 问：为什么不能在原分式中直接代入 h = 0？答：分母为 0；应先在 h != 0 时化简，再求极限。
