# Conuo Processor

Python 3.12 标准库实现的单批次索引处理器。它通过受保护的 Next.js 接口领取租约、读取已授权切块、调用真实 Embeddings 服务并提交向量；只有服务端确认当前版本及权限仍有效，且全部切块已提交后，才发布索引。

当前实现处理已有切块的向量化。文件解析仍在 Web 浏览器完成；这里尚未实现 PDF、DOCX、OCR 或网页解析，也没有安装 Celery、启动常驻服务或配置云调度。

## 配置与运行

无需安装 Python 依赖。在本目录执行：

```sh
python -m conuo_processor --max-jobs 5 --max-seconds 40
```

运行前通过操作系统或调度器注入以下环境变量。程序不自动加载 `.env`；[.env.example](.env.example) 仅列出占位字段，不包含可用凭据。

| 变量 | 要求 |
| --- | --- |
| `CONUO_PROCESSOR_ENDPOINT` | 完整 Next.js 地址，路径必须为 `/api/internal/indexing` |
| `CONUO_PROCESSOR_SECRET` | 与 Next.js 相同的专用服务端秘密，32–4096 个非空白 ASCII 字符 |
| `CONUO_EMBEDDING_BASE_URL` | Embeddings 兼容服务前缀，例如供应商文档给出的 `/v1` 地址；程序追加 `/embeddings` |
| `CONUO_EMBEDDING_API_KEY` | 供应商服务端密钥，不得使用 `NEXT_PUBLIC_` 暴露 |
| `CONUO_EMBEDDING_MODEL` | 明确指定返回 1536 维向量的模型；没有默认模型或供应商 |
| `CONUO_PROCESSOR_WORKER_ID` | 可选，默认 `python-bounded-worker`，1–80 个英文字母、数字、下划线或连字符 |

服务端还需完成数据库迁移与受保护接口配置。处理器不持有 Supabase 服务角色密钥，不直接连接数据库，不创建凭据。

URL 仅接受 HTTPS，或明确使用 `localhost`、`127.0.0.1`、`[::1]` 的本地 HTTP。禁止账号密码、查询参数、片段、反斜线、点路径与编码点路径；请使用供应商的规范 ASCII URL。两端的模型名称及规范化 Base URL 必须一致：每次动作都发送 `SHA256(JSON.stringify(['embedding-v1', baseUrl, model, 1536]))` 指纹，不一致由服务端拒绝。模型必须支持原生 1536 维浮点输出；程序不传递供应商可能不支持的 `dimensions` 参数。

配置真实服务后，上面的命令会实际发送资料正文，并可能产生模型费用。本次开发只运行本地测试服务，未调用真实模型、未执行真实 Supabase 云联调、未部署或启用付费资源。

## 处理边界

- 默认每次运行最多 5 个任务、总计 40 秒；参数只能调低。每次领取 1 个任务，租约 120 秒，每批读取最多 16 个切块。程序不内置循环等待或自动 HTTP 重试；外部调度器可以在后续时刻再次执行该命令。
- 每次读取由服务端预占账号每日字符额度，默认 UTC 日 200,000 字符，可由服务端配置；失败也计入。切块序号允许不连续，处理器只依据服务端 cursor 接续，不重算授权范围，不截断正文。
- 单个模型输入最多 24,000 字符，单批输入 UTF-8 共最多 120,000 字节；超过时明确报错。单次模型请求正文上限 124,096 字节，通用服务端请求及所有响应上限各 1 MiB。向量必须按唯一 index 对应输入、每条 1536 维、数值有限且绝对值不超过 `1e10`，并且不能全零。
- Embeddings 调用最多 20 秒，服务端动作最多 8 秒，均受本次总预算与取消信号约束。剩余时间不足时停止领取或处理，未发布的租约由服务端后续回收。数据库保留已确认的 cursor；未确认提交不会被当作成功，也不会贸然发布。
- 408、429、5xx、网络与超时等明确模型失败可向服务端报告为可重试；是否重试及退避由数据库决定，处理器不会立即重放同一任务。认证失败、非法响应或输入超限属于不可重试。失效租约、权限或版本变更停止本次处理，不操作其他租约。
- HTTP 不跟随重定向、不读取系统代理配置、不打印供应商响应、密钥、正文或租约令牌。取消会关闭连接并阻止后续提交；这不保证上游已经收到的请求会停止计费。标准库无法中途终止系统 DNS 解析，解析线程为 daemon，迟到的连接不会再发送请求；主调用仍按总预算退出。

标准输出为 JSON 行，仅含经过校验的 `jobId`（如已领取）、`state` 和安全 `code`。退出码：`0` 为无任务、完成或正常预算暂停；`1` 为失败、状态过期或未确认操作；`2` 为配置/参数错误；`130` 为收到取消。后续任务成功不会掩盖同一批次中先前的失败。

## 本地验证

```sh
python -B -W error::ResourceWarning -m unittest discover -s tests -v
```

测试仅在随机本地回环端口启动短期 HTTP 服务，结束后关闭。测试数学向量与任务服务替身只位于 `tests/`，生产代码没有模拟模型、默认成功结果或自动伪造向量。验证包含真实 HTTP 请求和 CLI 子进程，以及重定向、响应边界、取消、超时、失效租约、部分提交与失败退出行为；不代表真实 Supabase、真实供应商或跨机器并发已经验证。

Embeddings HTTP 字段依据 [OpenAI 官方 API 参考](https://developers.openai.com/api/reference/ruby/resources/embeddings/methods/create)。Vercel Cron、Queues 或其他调度触发适配仍需独立接入，本目录不会自行启用调度。
