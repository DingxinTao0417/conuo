Conuo 希望把文件、网页和笔记组织为可检索、可追溯的个人知识库。阅读时提出问题，回到原文核对依据，把自己的理解保存下来，下次从上次的问题继续。

**Web 版采用云端唯一正式存储，登录后使用。** 工作区、笔记、阅读进度和已接受的知识更新保存到 Supabase PostgreSQL，原件保存在私有 Storage。页面只用内存暂存编辑和上传字节，刷新后重新读取云端；本地与云端共存留给未来桌面版。详见 [Web 存储政策](docs/WEB_CLOUD_STORAGE.md)。

> **当前状态：首版 Web 开发中，已有可运行的云端工作台。** 支持资料与网页导入、历史阅读、笔记、知识整理审核和指定知识库导出；已接通普通搜索、用问题找原文、规范化资料索引、可选 pgvector 混合检索与 Python 有界索引处理器。Supabase PRODUCTION 已应用并核验 19 份迁移，包含历史版本单独清理的受限 RPC；真实账号已完成登录、云端 TXT 上传、第二浏览器恢复和原件下载，下载 SHA-256 与验收夹具一致。`20260914000800_fast_workspace_saves.sql`、`20260914120601_upload_intents.sql`、`20260914120700_organization_jobs.sql`、`20260915045450_annotation_utf16_text_anchors.sql` 与 `20260915060323_source_purge_saved_content_selection.sql` 五份迁移仅在本地准备，尚未应用到 PRODUCTION，需用户授权后才可执行；分别补齐保存路径、原件上传预留与清理、整理持久任务、批注准确位置和关联另存内容的选择清理。登录后的资料问答和 PDF 区域视觉已完成真实模型与请求账本联调；真实双账号隔离、完整双设备并发 CAS 矩阵及云调度仍待验收。完整 M0 未完成，也未部署。模型未配置时保留原文摘录；云端问答支持生成式回答与原文引用。Web App Manifest 已提供安装名称、图标和快捷入口；支持的浏览器在 HTTPS 部署后可加入桌面或主屏，但这不是离线包。

PDF 当前页已提供固定区域视觉学习，由支持图像的多模态模型直接解读截图、回答区域问题或生成一次性练习。解读按摘要、图中观察、分析推导和学习要点分节展示，正文、问答与练习支持 Markdown 和公式排版。截图只在用户明确点击发送时临时传输，结果绑定资料、版本、物理页和归一化矩形，截图默认不持久化。该流程不依赖 OCR，也不生成全文索引；扫描 PDF 正文仍不能检索。当前 DeepSeek `deepseek-flash` 已通过真实登录后的截图解读、图片问答和中文练习生成，服务端账本已记录完成；详见[区域视觉说明](docs/REGION_STUDY.md)。

**收集资料 → 阅读提问 → 核对原文 → 保存理解 → 继续学习**

PDF 阅读支持“单页／连续滚动”，可在读到中途切换并保持可用的页内位置；连续模式按实际物理页更新进度，附近页面按需绘制。手机端切换入口常驻阅读区上方，平板与宽屏沿用阅读工具。详见 [PDF 阅读模式](docs/PDF_READING_MODES.md)。

账号注销确认后，Web 停止该账号的任务与访问、清理当前页面的暂存内容，并保留会话封锁；刷新后由云端身份与注销闸门重新核验。当前 Web 不以旧 IndexedDB 缓存作为可用工作区，也不自动清理遗留副本。真实云端 Auth／Storage 注销与跨设备验收仍待完成，旧缓存格式和兼容边界见[原件与遗留缓存说明](docs/LOCAL_ORIGINALS.md)。

已应用的知识页 AI 更新可以先对照更新前、AI 更新后与当前内容，再局部撤回：保留能确认的后续独立编辑，重叠或重复位置由用户选择或纯文本合并。确认会新增历史并封存该任务，全保留也不能再采用剩余建议；Web 等待云端保存确认。尚未应用的审核勾选和编辑只在当前页面暂存，刷新不恢复。详见[知识页安全撤回](docs/KNOWLEDGE_UPDATE_WITHDRAWAL.md)。

## 快速开始

需要 **Node.js 24+** 和 npm。在仓库根目录执行：

```bash
npm install
npm run dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。先完成 Supabase 配置，再注册或登录使用工作台。未配置时显示配置提示，未登录时显示账号入口；不会创建匿名工作区。示例资料需要主动添加，首次打开不会自动混入演示内容。

开发与构建脚本会自动准备 PDF worker 和应用 Logo，无需手动复制。停止开发服务器可在运行终端按 `Ctrl+C`。

按[云端开发配置](docs/CLOUD_SETUP.md)设置 `apps/web/.env.local`、数据库迁移与 Auth 回调。环境变量示例在 [apps/web/.env.example](apps/web/.env.example)；`NEXT_PUBLIC_*` 公开变量只能使用项目 URL 和 publishable／anon key，不能放服务端特权密钥。可选生成式问答的模型密钥和 Supabase 请求账本密钥仅放服务端变量，配置方法见[模型服务配置](docs/MODEL_SETUP.md)。不要提交真实配置或在聊天中发送密钥。

Web 的“已保存”以云端确认结果为准；编辑留在当前页面不等于已保存。初始云端读取失败时保持加载错误，不创建空库或发起覆盖写入；保存未确认时提示重试，离开和退出会保护未保存内容，不提供“保留本机草稿并退出”。登录且保存确认后才能使用云端搜索；**新问答仍只检索原始资料**，普通搜索已包含笔记和已接受知识页，草稿默认排除。

普通搜索可先按笔记／知识页及创建时间筛选，再输入关键词；空关键词按所选类型浏览。类型与日期通过 URL 恢复，关闭 AI 不隐藏普通结果，资料标签与收藏不应用到笔记／知识页。批量添加标签会在云端保存确认后逐项展示结果，并仅重试失败项；详见[批量标签](docs/BULK_TAGS.md)。

批量关联学习空间和移入回收站也等待云端保存确认，逐项显示已处理、无需修改和失败。保存失败可重存最新快照，保留首次成功项；继续审核只带入本次成功新增的资料。详见[批量资料操作](docs/BULK_SOURCE_ACTIONS.md)。

资料分析已通过真实模型生成摘要、8 个标签与 5 个主题建议；两份资料生成 3 个知识主题，人工接受后的知识页及引用已云端保存并刷新恢复。当前采用仅限开发环境的手动页面运行，关闭页面会停止请求。自动分析默认关闭，生产持久整理队列、processor 与调度尚未上线，详见[云端验收](docs/CLOUD_E2E_ACCEPTANCE.md)。独立的向量任务已保存在数据库，支持租约、检查点、取消和重试；[Python 处理器](apps/processor/README.md)需显式运行，默认最多 5 项、40 秒。整理建议需人工审核后应用。

## 技术栈

设置页提供 AI 请求用量、UTC 重置规则和本机时间；缺少服务端账本配置时显示未知，不制造零余额。正式原件按当前账号权限从私有 Storage 读取，导入与恢复过程中只在内存暂存。旧匿名资料仅在用户明确发起“导入旧版资料”时只读访问，校验后恢复为当前云端账号的新副本；旧资料和原件保留，不自动合并或删除。详见[模型配置](docs/MODEL_SETUP.md)和[原件与遗留缓存说明](docs/LOCAL_ORIGINALS.md)。

| 层级           | 选型与状态                                                                                                                                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Web 与 API     | Next.js 16 · React 19 · TypeScript；App Router 与 `/api/v1/` Route Handlers                                                                                                                                                              |
| 样式           | Tailwind CSS 4 与组件样式；知识库采用书封式文件管理布局，阅读器延续 TraeWork 原型                                                                                                                                                        |
| 阅读与编辑     | PDF.js · Tiptap；DOCX 文本提取使用 Mammoth；PDF 区域截图在浏览器内生成，仅由明确发送动作交给多模态模型                                                                                                                                   |
| 会话暂存       | 内存快照与待上传原件；浏览器内文本切块与关键词检索                                                                                                                                                                                       |
| 云端账号与文件 | Supabase Auth + Storage；PRODUCTION 已核验登录配置、私有桶策略及 19 份迁移，并在真实单账号完成 TXT 上传、第二浏览器恢复和原件下载（SHA-256 与夹具一致）。双账号隔离与完整双设备并发 CAS 矩阵待验收；快速保存迁移仅在本地准备，尚未应用。 |
| 数据库         | Supabase PostgreSQL；原子同步资料、不可变版本与内容块，JSONB 工作区仍作为 3 MiB 兼容保存协议                                                                                                                                             |
| 模型接入       | 服务端 Chat Completions 适配器；本机 DeepSeek `deepseek-flash` 已通过真实 PNG 多模态请求。既有服务端账本密钥已配置到忽略的本地环境；真实登录问答、区域视觉、手动资料分析及知识审核保存已通过，生产后台与 Vercel 尚未部署。               |
| 检索与任务     | pgvector、持久索引队列、Python 3.12 有界 CLI；真实 SQL 与本地 HTTP 已测试，供应商和云调度待验证                                                                                                                                          |
| 部署目标       | Vercel；项目根目录设为 `apps/web`，尚未部署                                                                                                                                                                                              |

精确依赖版本见 [apps/web/package.json](apps/web/package.json) 和锁文件；完整目标架构见[技术方案](docs/TECH_STACK.md)。

## 路线图与边界

- **M0 · Web 开发中**：已有知识页审核、类型化关系、文件与网页版本链、普通搜索及资料索引管线；继续验证真实召回与模型质量，部署并验收后台调度，补齐完整数据模型与生命周期。
- **后续 Web**：按使用反馈评估整库 OCR、更多文件格式、后台知识整理，以及完整练习作答与回顾。首版 PDF 区域的一次性练习不代表这些系统已经完成。
- **其他平台**：目前只开发响应式 Web。手机、iPad、Windows、macOS 独立客户端在 Web 核心功能稳定后另行评估，尚未排期；桌面版本地与云端共存需单独设计和验收。

资料彻底删除和账号注销已有协议与受保护服务端执行入口：[前者](docs/PERMANENT_DELETION.md)默认保留另存内容，新本地代码支持逐篇笔记／知识页含全部历史和整对话选择清理，但对应迁移仍待应用；后者要求影响预览、邮箱/密码/`DELETE` 确认，通过 Storage/Auth 两阶段 outbox 停止访问和清理原件。真实单账号 Storage 上传、恢复和下载已验收；双账号 Storage 隔离、Auth Admin、Cron 和完整双设备并发仍待联调。旧浏览器缓存删除保护的历史实现与验证不代表当前 Web 存储模式，完整 M0 和服务端灾难恢复仍有待完成项。个人 ZIP 可恢复为新增云端副本，详见[备份恢复](docs/BACKUP_RESTORE.md)。整理记录当前最多 1000 个，和其他内容共用 3 MiB 工作区快照上限；设置页可在影响确认后清理已收起、失败和已停止的终态记录，待审核及执行中的任务会保留。详细范围以 [PRD](docs/PRD.md) 为准，实际进度以[开发状态](docs/IMPLEMENTATION_STATUS.md)为准。

文件导入与替换上限为每个 30 MiB；浏览器每批最多 20 个文件、合计 150 MiB。入口仍按当前账号快照估算 512 MiB 保留原件准入范围，这是保守校验，不是本机存储额度或正式云端套餐承诺；精确 Storage 配额及上传预留需要第 21 份待迁移。导入在当前页面内存中重新判重并检查容量，再由保存队列上传原件、提交云端 revision CAS。初始加载、刷新和跨页面重载只读取云端，其他标签页不以共享 IndexedDB 交换工作区。发生云端冲突时保留当前页面编辑供明确处理，不自动合并，也不提供可跨刷新恢复的本机草稿。每份资料最多保留 200 个历史版本，全部版本文字与片段共用 3 MiB 工作区上限，不自动裁剪历史。版本记录可在影响确认后把一个确切旧版恢复为当前版；登录且保存完成后，也可通过服务端影响预览和“清理”确认单独清理历史版本，旧引用不会被替换。解析仍在浏览器执行；真实单账号原件、资料问答与区域视觉已联调，双账号隔离和完整双设备并发仍待验收。
